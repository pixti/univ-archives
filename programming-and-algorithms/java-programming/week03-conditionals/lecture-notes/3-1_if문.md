## 1. if 문

가장 기본적인 조건문은 아래와 같은 형식이다.

```java
if (조건식) {
    실행문1;
    ...
    실행문n;
}
```

실행 문장이 하나면 중괄호 `{ }`를 생략할 수 있다.

```java
if (조건식) 실행문1;
```

| Java | Python |
|---|---|
| `if (조건식) { ... }` | `if 조건식:` + 들여쓰기 |
| 조건식을 **괄호 `( )`로 감싼다** | 괄호 없이 쓰고 **콜론 `:`**을 붙인다 |
| 블록을 **중괄호 `{ }`**로 구분한다 | 블록을 **들여쓰기**로 구분한다 |

> 참고: **조건식은 반드시 `boolean`이어야 한다**
> - 파이썬은 `if x:`처럼 숫자나 문자열도 조건으로 쓸 수 있다(0, 빈 문자열은 거짓).
> - 자바는 조건식의 결과가 `true`/`false`가 아니면 **컴파일 에러**가 난다.
>
> 📝 **필기 (퀴즈 · 조건문 2번):** "파이썬에서는 참이지만 자바에서는 boolean이 아니면 문법 오류임."
> - `int x = 3, y = 5, z = 2;`일 때
> - `if (x == z + 1)` → 3 == 3이므로 **참**
> - `if (z = 1)` → 대입식의 결과는 int 1 → **문법 오류**
> - `if (x)` → int → **문법 오류**
> - `if (z = 3 == x)` → `3 == x`가 먼저 계산되어 true가 된다. 그다음 int 변수 z에 boolean을 대입하려 하므로 **문법 오류**다.
> → [`quiz/ConditionalQuiz.java`](../quiz/ConditionalQuiz.java)

> 💡 중괄호 생략은 실행문이 **딱 하나**일 때만 가능하다. 두 줄을 들여쓰기만 해 두면 두 번째 줄은 if와 상관없이 항상 실행된다. 처음 배울 때는 한 줄이어도 중괄호를 쓰는 편이 안전하다.
> ```java
> if (x > 0)
>     System.out.println("양수");
>     System.out.println("이 줄은 항상 실행된다!");  // 들여쓰기는 의미 없음
> ```

## 2. if-else 문

조건을 만족하는 경우와 그렇지 않은 경우를 구분할 때 `if-else`를 쓴다.

```java
if (조건식) {
    실행문1;
    ...
    실행문n;
}
else {
    실행문21;
    ...
    실행문2n;
}
```

```python
# Python
if 조건식:
    실행문1
else:
    실행문21
```

### 복합 조건식 예

나이가 40 이상이고 키가 170 이상이면 "자격이 됩니다", 그렇지 않으면 "자격이 안 됩니다"를 출력한다.

```java
if (age >= 40 && height >= 170) {
    System.out.println("자격이 됩니다");
}
else {
    System.out.println("자격이 안 됩니다");
}
```

### 중첩 if 문 예

같은 내용을 if 문 안에 if 문을 넣어서 쓸 수도 있다.

```java
if (age >= 40) {
    if (height >= 170)
        System.out.println("자격이 됩니다");
    else
        System.out.println("자격이 안됩니다");
}
else
    System.out.println("자격이 안됩니다");
```

> - 복합 조건식(`&&`) 버전이 더 짧고 읽기 쉽다.
> - 중첩 버전은 "나이 미달"과 "키 미달"을 **다른 메시지로 구분**하고 싶을 때 유리하다.
> - `else`는 **가장 가까운, 짝이 없는 `if`**와 짝을 이룬다(dangling else). 중첩할 때는 중괄호로 짝을 분명히 해 두자.
> - ⚠ 슬라이드 코드는 `“자격이 됩니다”`처럼 **둥근 따옴표(“ ”)**로 되어 있다. 그대로 붙여 넣으면 컴파일 에러가 나므로 곧은 따옴표(`" "`)로 바꿨다. 이 주차 슬라이드 전체가 그렇다.
>
> → [`examples/Qualification.java`](../examples/Qualification.java)

> 📝 **필기 (퀴즈 · 조건문 1번):** "자바에서는 `if (20 <= age <= 65) {}` 같은 문장이 허용되지 않음. 반드시 and 또는 or 같은 걸로 쪼개야 함."
> - `20 <= age`가 먼저 계산되어 boolean이 된다. 그러면 `boolean <= 65` 비교가 되어 컴파일 에러가 난다.
> - 올바른 식은 `if (age >= 20 && age <= 65) count++;`이다.

## 3. else if 문

조건에 따라 작업을 여러 갈래로 나누고 싶으면 `else if`를 쓴다.

```java
if (조건식1)
    A
else if (조건식2)
    B
...
else if (조건식n)
    N
else
    M
```

```python
# Python 은 else if 를 줄여서 elif
if 조건식1:
    A
elif 조건식2:
    B
else:
    M
```

> **조건은 위에서부터 순서대로 검사한다!**
> 어느 조건이 true이면 그 블록만 실행하고, **나머지 조건은 검사하지 않는다.**

### else if 문 예: 점수에 따른 학점

```java
if (score >= 90)
    System.out.println("A 학점 입니다");
else if (score < 90 && score >= 80) System.out.println("B 학점 입니다");
else if (score < 80 && score >= 70) System.out.println("C 학점 입니다");
else if (score < 70 && score >= 60) System.out.println("D 학점 입니다");
else
    System.out.println("F 학점 입니다");
```

`score < 90`처럼 **불필요한 조건은 생략할 수 있다!** 두 번째 조건까지 왔다는 것은 이미 `score >= 90`이 거짓이라는 뜻이다. 즉 `score < 90`은 항상 참이다.

### else if 문 예 (수정)

```java
if (score >= 90)
    System.out.println("A 학점 입니다");
else if (score >= 80)
    System.out.println("B 학점 입니다");
else if (score >= 70)
    System.out.println("C 학점 입니다");
else if (score >= 60)
    System.out.println("D 학점 입니다");
else
    System.out.println("F 학점 입니다");
```

> 📝 **필기 (퀴즈 · 조건문 3-②번):** 조건을 거르는 **순서**가 틀리면 논리 오류가 난다.
> ```java
> float grade = 3.0;            // 문법 오류: 3.0 은 double → 3.0f 로 써야 함
> if (grade >= 2.0)
>     System.out.println("C");
> else if (grade >= 3.0)        // 논리 오류: 3.0 이상이면 이미 위에서 걸러져 C 가 출력됨
>     System.out.println("B");
> ```
> "2.0보다 크면 C, 3.0 이상이면 B. 맞는 것으로 보이지만 3.0인 경우도 C를 출력하게 되는 논리 오류가 있음."
> → 위 학점 예제처럼 **큰 값부터** 검사해야 한다(`>= 3.0` → B를 먼저, 그다음 `>= 2.0` → C). → [`quiz/ConditionalQuiz.java`](../quiz/ConditionalQuiz.java)

## 4. [실습] 3개의 정수 중 중간값 찾기

```java
import java.util.Scanner;

public class Median {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("첫 번째 숫자 (음수도 가능) >> ");
        int s1 = sc.nextInt();
        System.out.println("두 번째 숫자 (음수도 가능) >> ");
        int s2 = sc.nextInt();
        System.out.println("세 번째 숫자 (음수도 가능) >> ");
        int s3 = sc.nextInt();
        sc.close();

        int medianVal;
        if (s1 > s2) {
            if (s2 > s3)
                medianVal = s2;      // s1 > s2 > s3
            else if (s3 > s1)
                medianVal = s1;      // s3 > s1 > s2
            else
                medianVal = s3;      // s1 >= s3 >= s2
        }
        else {
            if (s1 > s3)
                medianVal = s1;      // s2 >= s1 > s3
            else if (s2 < s3)
                medianVal = s2;      // s3 > s2 >= s1
            else
                medianVal = s3;      // s2 >= s3 >= s1
        }
        System.out.println("중간값 : " + medianVal);
    }
}
```

```
첫 번째 숫자 (음수도 가능) >>
5
두 번째 숫자 (음수도 가능) >>
7
세 번째 숫자 (음수도 가능) >>
9
중간값 : 7
```

> ⚠ 슬라이드 코드에서 바로잡은 부분:
> - 클래스명 `Meadian`과 변수명 `meadianVal`은 철자 오류라 `Median`, `medianVal`로 고쳤다.
> - 세 번째 입력 안내문이 `"두 번째 숫자"`로 되어 있어 `"세 번째 숫자"`로 고쳤다. 실행 화면 캡처에도 "두 번째"가 두 번 나온다.
>
> 💡 실행 화면 캡처의 코드는 `s1 > s2` 블록 안이 슬라이드와 조금 다르다. `else if (s1 > s3) → s3`, `else → s1`이다. 비교 순서만 다르고 두 방식 모두 맞다.
>
> 💡 먼저 `s1 > s2`로 둘의 대소를 정해 둔다. 그다음 s3가 어디에 끼어드는지(맨 위, 가운데, 맨 아래)만 따지면 된다고 생각하면 이해하기 쉽다.
