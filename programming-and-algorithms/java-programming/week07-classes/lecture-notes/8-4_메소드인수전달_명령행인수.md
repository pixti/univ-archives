## 1. 메소드 인수 전달

- 메소드를 호출할 때 **기본 자료형** 인자의 값은 **call-by-value**로 전달된다.
- **레퍼런스형**인 경우는 **call-by-reference** 방식으로 전달된다.

```java
public class SwapTest {
    public static void main(String[] args) {
        int x= 5, y=3;
        swap(x, y); // 값이 바뀌지 않음
        System.out.println(x);
        System.out.println(y);
    }
    public static void swap(int a, int b) {
        int tmp;
        tmp = a;
        a = b;
        b = tmp;
    }
}
```

```
main            swap(int a, int b)
x [ 5 ] ──복사──▶ a [ 5 ] → [ 3 ]
y [ 3 ] ──복사──▶ b [ 3 ] → [ 5 ]      tmp [ 5 ]
                  ↑ 바뀌는 것은 복사본뿐
결과: 5, 3 (그대로)
```

- **배열**은 call-by-reference 방식으로 호출된다.

```java
public class SwapTest {
    public static void main(String[] args) {
        int [] arr = new int[] {5, 3};
        swap(arr, 0, 1); // 값이 바뀜
        System.out.println(arr[0]);
        System.out.println(arr[1]);
    }
    public static void swap(int[] arr, int idx1, int idx2) {
        int tmp;
        tmp = arr[idx1];
        arr[idx1] = arr[idx2];
        arr[idx2] = tmp;
    }
}
```

```
main  arr ──┐
            ├──▶ [ 5 | 3 ]  →  [ 3 | 5 ]
swap  arr ──┘    (같은 배열 객체)
결과: 3, 5 (바뀜)
```

> 참고:
> - ⚠ 슬라이드 3의 배열 swap은 `public void swap(...)`처럼 **static이 없다**. 그런데 static인 main에서 바로 호출하므로 컴파일 오류가 난다. 위에서는 `static`을 붙였다. (퀴즈 8번과 같은 종류의 오류)
>   ```
>   error: non-static method swap(int[],int,int) cannot be referenced from a static context
>   ```
> - 💡 엄밀히 말하면 자바는 **항상 값으로 전달(call-by-value)**한다. 레퍼런스형은 "레퍼런스 값(주소)"이 복사되어 넘어간다. 그래서 두 변수가 같은 객체를 가리키게 되고, 결과적으로 call-by-reference처럼 동작한다. 그래서 메소드 안에서 `arr = new int[]{9, 9};`처럼 **새 배열을 대입**하면 main의 배열은 바뀌지 않는다. 메소드 안의 `arr`만 다른 곳을 가리키게 될 뿐이다.
> - 💡 두 swap은 매개변수가 달라서 한 클래스 안에 **중복정의(오버로딩)**로 같이 둘 수 있다. [`examples/SwapTest.java`](../examples/SwapTest.java)는 두 슬라이드를 한 파일로 합친 것이다.

## 2. 배열 인수

- 배열도 **객체**이기 때문에 값이 아닌 **참조(레퍼런스)**가 전달된다.
- 배열을 인수로 전달할 때는 **배열명만** 인수로 전달한다. 메소드 선언부에서는 배열의 레퍼런스가 넘어온다고 표시한다.

```java
// 배열을 선언
double[] hourlyTemperatures = new double[ 24 ];
// 메소드 호출
ModifyArray( hourlyTemperatures );
// 메소드 선언
void ModifyArray( double[] b ) { ... }
```

- 메소드에서 배열을 인수로 받아들이는 예: 배열은 레퍼런스가 값으로 전달되기 때문에 작업 후 **원래 배열의 원소도 바뀐다.**

```java
public static void main(String[ ] args){
    int[] t = new int[] {1, 2, 3};
    ModifyArray( t );
    for(int j=0; j < t.length; j++) System.out.print(t[j] + " ");
    System.out.println();
}
static void ModifyArray( int[] b )
{
    for (int j=0; j < b.length; j++) b[j] *= 2;
}
```

```
2 4 6
```

> 참고:
> - ⚠ 슬라이드의 `System.out.print(t[j] + “ ”)` 스마트 따옴표는 일반 따옴표로 바꿨다.
> - 💡 실습 클래스1 4번 DynamicArray의 `append`도 같은 원리를 쓴다. 용량이 부족하면 새 배열을 만들어 값을 복사한 뒤 `array = newArray;`로 필드가 새 배열을 가리키게 한다.

## 3. [실습] 배열 데이터 메소드에서 변경하기

```java
import java.util.Random;

public class ArrayArgument {
    public static void main(String[] args) {
        int [] array = new int[10];
        Random rnd = new Random();
        for(int i=0; i < 10; i++) array[i] = rnd.nextInt();
        System.out.print("변경 전 : ");
        printArray(array);
        increaseArray(array);
        System.out.print("변경 후 : ");
        printArray(array);
    }
    public static void increaseArray(int[] arr) {
        for(int i=0; i < arr.length; i++) arr[i]++;
    }
    public static void printArray(int[] arr) {
        for(int i=0; i < arr.length; i++) System.out.print(arr[i] + " ");
        System.out.println();
    }
}
```

```
변경 전 : -1095185654 -1848370672 -16527252 616845863 -199029536 1150806519 -1088861535 -545424265 39827381 -116428477
변경 후 : -1095185653 -1848370671 -16527251 616845864 -199029535 1150806520 -1088861534 -545424264 39827382 -116428476
```

> 참고:
> - 💡 `rnd.nextInt()`는 int 범위 전체(음수 포함)에서 난수를 만든다. 그래서 실행할 때마다 값이 다르다. `rnd.nextInt(100)`처럼 범위를 주면 0~99 사이의 값이 나온다.
> - 💡 주사위처럼 1~6이 필요하면 `rnd.nextInt(6) + 1` 또는 `(int)(Math.random() * 6) + 1`을 쓴다. (과제 클래스2 1번 Dice)

## 4. 명령행 인수

- `main`은 **String 타입의 배열**을 인수로 받는다.
- foreach 문을 이용해 출력할 수 있다.
- 이클립스에서 명령행 인수를 쓰려면 **Run Configuration** 메뉴를 이용한다.

```java
class CommandLineTest{
    public static void main(String[ ] args) {
        for (String arg : args)
        {
            System.out.println(arg);
        }
    }
}
```

```
> java CommandLineTest aaa bbb
aaa
bbb
```

- 이클립스 설정 방법: **Run → Run Configurations → Arguments 탭**을 연다. **Program arguments** 칸에 원하는 명령행 인수들을 입력한다.

```
┌ Run Configurations ─────────────────────────────┐
│  Main │ (x)= Arguments │ JRE │ ...              │
│  Program arguments:                              │
│  ┌────────────────────────────────────────────┐ │
│  │ aaa bbb                                    │ │
│  └────────────────────────────────────────────┘ │
│                                 [Apply] [Run]    │
└──────────────────────────────────────────────────┘
```

- 명령행 인수도 String 배열이기 때문에 **첨자**를 이용해 접근할 수 있다.

```java
class CommandLineTest{
    public static void main(String[ ] args) {
        System.out.println(args[0]); // aaa
        System.out.println(args[1]); // bbb
    }
}
```

> 참고:
> - 💡 인수 없이 실행하면 `args.length`가 0이라서 `args[0]`에서 `ArrayIndexOutOfBoundsException`이 난다. [`examples/CommandLineTest.java`](../examples/CommandLineTest.java)에는 길이를 검사하는 코드를 추가했다.
> - 💡 공백이 들어간 값을 인수 하나로 넘기려면 따옴표로 묶는다: `java CommandLineTest "hello world"` → `args[0]`은 `"hello world"`다.
> - 💡 명령행 인수는 항상 문자열이다. 숫자로 쓰려면 `Integer.parseInt(args[0])`처럼 변환한다.
> - ⚠ 슬라이드 9의 `Java xxx aaa bbb`는 `java`의 오타다. 명령어는 소문자로 쓴다.
> - ⚠ 표지 제목이 `[ 클래스3 ]`으로 되어 있지만 파일 이름으로 보면 클래스4 자료다.
