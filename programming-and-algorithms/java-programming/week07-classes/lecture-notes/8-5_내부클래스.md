## 1. 내부 클래스

- 클래스 내부(outer class)에 다시 클래스(**inner class**)를 정의할 수 있다.
- 내부 클래스는 외부 클래스의 필드, 메소드에 **마음대로 접근**할 수 있다.

```java
class Outer{
    int num = 10;
    private class Inner{
        public void print(){
            System.out.println("This is an inner class : " + num); // outer의 num 사용
        }
    }
    void display_Inner(){
        Inner inner = new Inner();
        inner.print();
    }
}
```

- 반대로 **Inner의 private도 Outer에서 접근**할 수 있다.

```java
class Outer {
    int num = 10;
    private class Inner{
        private int x=5;
        public void print(){
            System.out.println("This is an inner class : " + num);
        }
    }
    void display_Inner(){
        Inner inner = new Inner();
        System.out.println(inner.x); // inner의 private도 outer에서 접근
        inner.print();
    }
}
```

```
5
This is an inner class : 10
```

> 참고:
> - 💡 바깥 클래스와 내부 클래스는 서로의 private 멤버에 접근할 수 있다. private의 범위가 "가장 바깥 클래스의 `{ }` 전체"이기 때문이다.

## 2. 다른 클래스에서 내부 클래스 객체 만들기

- 내부 클래스를 **public이나 접근자 없이** 선언하면, 다른 클래스에서도 내부 클래스 타입의 객체를 직접 생성해 쓸 수 있다.

```java
public class InnerTest {
    public static void main(String[] args) {
        Outer outer = new Outer();
        Outer.Inner inner = outer.new Inner();
        inner.print();
    }
}
// % 앞의 Inner 클래스의 접근자를 private에서 public으로 바꾼 후 실행
```

```
This is an inner class : 10
```

```
outer ──▶ [ Outer : num = 10 ]
                 ▲
                 │ 바깥 객체를 기억
inner ──▶ [ Inner : x = 5 ]   → print()의 num은 "이 outer"의 num
```

> 참고:
> - 📝 **필기 (퀴즈 9번) Java 내부 클래스 문법:** `new A`, `new B`로 각각 생성했었는데, B가 **내부 클래스(inner class)**가 되었다. 그래서 `A outer = new A(); B inner = new B();`에서 B 클래스에 접근할 때는 아래처럼 바꾼다.
>   ```java
>   A.B inner = outer.new B();
>   ```
> - 📝 **필기 (퀴즈 9번, AI 설명):** 인스턴스 멤버 클래스(내부 클래스)는 **외부 클래스의 객체가 먼저 있어야** 만들 수 있다. 그래서 `outer.new B()`처럼 외부 객체를 통해 생성하고, 타입도 `A.B`처럼 바깥 클래스 이름을 붙여 쓴다.
> - 📝 **필기 (실습 클래스2 1번):** 내부 클래스의 객체는 `외부객체.new 내부클래스()` 형태로 생성한다. → `Circle.Point p1 = c1.new Point();`
> - ⚠ Inner가 `private`이면 바깥에서 `Outer.Inner`를 쓸 수 없어 오류가 난다. 슬라이드의 `privat`은 `private`의 오타다.
>   ```
>   error: Outer.Inner has private access in Outer
>   ```
> - 💡 내부 클래스 앞에 `static`을 붙이면(정적 중첩 클래스) 외부 객체 없이 `new Outer.Inner()`로 만들 수 있다. 대신 바깥의 일반 필드(`num`)는 직접 쓸 수 없다. static 메소드에서 일반 필드를 못 쓰는 것과 같은 이유다.

## 3. 메소드 내부 클래스 (method-local inner class)

- 메소드 안에서도 클래스를 선언해 쓸 수 있다. 이것을 **메소드 내부 클래스(method-local inner class)**라고 한다.
- 지역 변수처럼 **메소드 안에서만** 사용할 수 있다.
- `public`, `private`는 붙일 수 없다. `abstract`나 `final`을 붙이거나 접근자 없이 쓴다.

```java
public class InnerTest {
    public static void main(String[] args) {
        Outer outer = new Outer();
        outer.display_Inner();
    }
}

class Outer {
    int num = 10;
    void display_Inner() {
        class Inner {                 // 접근자 없이
            int x=5;
            public void print(){
                System.out.println("This is an inner class : " + num);
            }
        }
        Inner inner = new Inner();
        System.out.println(inner.x);
        inner.print();
    }
}
```

```
5
This is an inner class : 10
```

> 참고:
> - ⚠ 슬라이드 6의 코드는 메소드 안에서 `private class Inner`로 선언했다. 바로 앞 슬라이드의 설명("public, private는 불가")과 맞지 않고, 실제로 컴파일 오류가 난다. 위 코드는 `private`을 지웠다.
>   ```
>   error: illegal start of expression
>   ```
> - 💡 지역 변수에 `public`/`private`를 붙일 수 없는 것과 같은 이유다. 어차피 메소드 밖에서는 보이지 않으므로 접근 제어가 의미 없다.

## 4. [실습] 내부 클래스와 일반 클래스로 선언할 경우의 차이

### (1) MyPoint 클래스를 내부 클래스로 작성

- MyPoint 클래스를 MyRectangle 클래스의 내부 클래스로 정의하면, MyRectangle 클래스에서 MyPoint를 바로 쓸 수 있다.
- main에서 MyPoint를 쓸 때는 **외부 클래스 객체를 먼저 만든 뒤** 내부 클래스 객체를 만든다.

```java
public class MyRectangleTest {
    public static void main(String[] args) {
        MyRectangle r1 = new MyRectangle();
        r1.setX(10); r1.setY(10); r1.setWidth(5); r1.setHeight(4);
        System.out.println("면적은 " + r1.getArea() + "입니다.");
        MyRectangle.MyPoint p = r1.new MyPoint();
        p.setX(3); p.setY(5);
        System.out.println(p.getX() + ", " + p.getY());
    }
}

class MyRectangle {
    private MyPoint corner = new MyPoint(); // 필드 정의
    private int width, height;
    public int getX() {return corner.x;}    // 메소드 정의
    public void setX(int newX) {corner.x = newX;}
    public int getY() {return corner.y;}
    public void setY(int newY) {corner.y = newY;}
    public int getWidth() {return width;}
    public void setWidth(int newW) {width = newW;}
    public int getHeight() {return height;}
    public void setHeight(int newY) {height = newY;}
    public void resize(int newW, int newH) {width = newW; height = newH;}
    public int getArea() {return width *height;}
    class MyPoint {
        private int x, y;
        public int getX() {return x;}             // x값을 읽는 기능
        public void setX(int newX) {x = newX;}    // x값을 변경하는 기능
        public int getY() {return y;}             // y값을 읽는 기능
        public void setY(int newY) {y = newY;}    // y값을 변경하는 기능
    }
}
```

### (2) MyPoint 클래스를 일반 클래스로 작성

```java
public class MyRectangleTest {
    public static void main(String[] args) {
        MyRectangle r1 = new MyRectangle();
        r1.setX(10); r1.setY(10); r1.setWidth(5); r1.setHeight(4);
        System.out.println("면적은 " + r1.getArea() + "입니다.");
        MyPoint p = new MyPoint();
        p.setX(3); p.setY(5);
        System.out.println(p.getX() + ", " + p.getY());
    }
}

class MyRectangle {
    private MyPoint corner = new MyPoint();   // 필드 정의
    private int width, height;
    public int getX() {return corner.getX();} // 메소드 정의
    public void setX(int newX) {corner.setX(newX);}
    public int getY() {return corner.getY();}
    public void setY(int newY) {corner.setY(newY);}
    ... (width, height, resize, getArea는 (1)과 같음)
}

class MyPoint {
    private int x, y;
    public int getX() {return x;}
    public void setX(int newX) {x = newX;}
    public int getY() {return y;}
    public void setY(int newY) {y = newY;}
}
```

```
면적은 20입니다.
3, 5
```

| | (1) 내부 클래스 | (2) 일반 클래스 |
|---|---|---|
| MyRectangle에서 좌표 접근 | `corner.x` (private에 **직접** 접근 가능) | `corner.getX()` (getter를 거쳐야 함) |
| main에서 MyPoint 생성 | `r1.new MyPoint()` (외부 객체 필요) | `new MyPoint()` |
| 타입 이름 | `MyRectangle.MyPoint` | `MyPoint` |
| 쓰임 | MyRectangle 전용 부품일 때 | 여러 클래스가 함께 쓸 때 (Circle, Rectangle …) |

> 참고:
> - 💡 (2)에서 `corner.x`처럼 쓰면 `error: x has private access in MyPoint` 오류가 난다. MyPoint가 MyRectangle 밖의 별도 클래스이기 때문이다.
> - 💡 두 경우 모두 MyRectangle이 MyPoint를 필드로 **가지고 있다**. 이런 구조를 **포함 관계(Composition)**라고 한다. (과제 클래스2 4번, 실습 클래스2 1번)
> - 📝 **필기 (실습 클래스2 1번):** Circle 안에서 중심 좌표를 읽을 때 `this.center.getX()`, `center.getX()`, `this.getCenter().getX()`, `getCenter().getX()` 네 가지가 모두 같은 결과다. 마지막 두 개처럼 메소드를 이어 부르는 것을 **메서드 체이닝**이라고 한다.
