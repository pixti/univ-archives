## 1. 클래스 정의

- 클래스는 **필드(데이터)**와 필드를 이용하는 **메소드(기능)**로 구성된다.

```java
접근수정자 class 클래스명 {
    필드 선언들
    메소드 정의들
}
```

- 접근수정자에는 `public`, `abstract`, `final` 또는 **생략**이 올 수 있다.
  - **public**: 클래스 외부(다른 패키지 또는 프로그램)에서 사용할 수 있다. public으로 선언된 클래스를 다른 패키지에서 쓰려면 `import`문으로 그 클래스의 패키지를 알려주어야 한다.
  - **생략**: 다른 패키지에서는 사용할 수 없고, 같은 패키지 안의 다른 클래스에서만 사용할 수 있다.

```java
// MyApplication.java 파일
package bmkim.java;

public class MyApplication {          // 외부에 공개할 필요가 있어 public으로 선언
    public static void main(String[] args) {
        MyMainClass c = new MyMainClass();
        ...
    }
}

class MySecondClass {                 // 외부에 공개할 필요가 없어 접근수정자 생략
    ...
}
```

> 참고:
> - 📝 **필기 (퀴즈 5번):** 하나의 .java 소스 파일 안에는 public class를 **단 하나만** 선언할 수 있다. public class의 이름은 **파일명과 정확히 일치**해야 한다.
> - 📝 **필기 (퀴즈 1번, AI 설명) 클래스와 객체의 차이:**
>
>   | 구분 | 클래스 (Class) | 객체 (Object, Instance) |
>   |---|---|---|
>   | 의미 | 객체를 만들기 위한 **설계도(틀, Blueprint)** | 클래스를 바탕으로 만든 **실체** |
>   | 메모리 | 메모리에 직접 할당되지 않는 추상적인 개념 | `new`로 **Heap**에 실제로 생성됨 |
>   | 특징 | 필드와 메소드의 "모양"을 정의 | 각자 고유한 상태(필드 값)와 행동(메소드)을 가짐 |
>
> - 💡 이 저장소의 예제 파일도 public class(main이 있는 클래스) 하나와 public이 없는 보조 클래스들을 한 파일에 넣었다. 그래서 `java 파일명.java`로 바로 실행할 수 있다.
> - ⚠ 슬라이드 코드의 `MyMainClass`는 정의되어 있지 않다. 아래에 선언한 `MySecondClass`를 가리키려던 것으로 보인다.

## 2. 필드 선언

- 필드 선언부는 객체들이 유지해야 할 데이터를 저장하는 변수들을 선언하는 곳이다.
- **객체를 생성할 때마다 고유의 필드가 따로 존재**한다. 그래서 필드를 쓸 때는 객체식별자와 함께 필드명을 적어야 한다.

```java
public class MyRectangle {
    int x, y, width, height;
    …
}
```

```java
MyRectangle ob1 = new MyRectangle();
MyRectangle ob2 = new MyRectangle();
ob1.x=0; ob1.y=0; ob1.width=10; ob1.height=10;
ob2.x=5; ob2.y=5; ob2.width=15; ob2.height=10;
System.out.println("위치 : " + ob1.x + ", " + ob1.y + " 폭 : " + ob1.width + " 높이 : " + ob1.height);
System.out.println("위치 : " + ob2.x + ", " + ob2.y + " 폭 : " + ob2.width + " 높이 : " + ob2.height);
```

```
 Stack           Heap
┌─────┐     ┌──────────────────────────────┐
│ ob1 │────▶│ x=0  y=0  width=10  height=10│
├─────┤     └──────────────────────────────┘
│ ob2 │────▶┌──────────────────────────────┐
└─────┘     │ x=5  y=5  width=15  height=10│
            └──────────────────────────────┘
```

```
위치 : 0, 0 폭 : 10 높이 : 10
위치 : 5, 5 폭 : 15 높이 : 10
```

- 필드에는 기본 자료형 변수뿐 아니라 **객체의 레퍼런스를 저장하는 변수**도 선언할 수 있다.

```java
public class MyPoint {
    int x, y; // 좌표값
}
public class MyRectangle {
    MyPoint origin = new MyPoint();
    int width, height; // 폭과 높이
    ...
}
```

> 참고:
> - 📝 **필기 (퀴즈 1번, AI 설명) 데이터 멤버(필드)와 지역 변수의 차이:**
>
>   | 구분 | 필드 (멤버 변수) | 지역 변수 |
>   |---|---|---|
>   | 선언 위치 | 클래스 블록 안, 메소드 **밖** | 메소드 · 생성자 · 블록 **안** |
>   | 생성 / 소멸 | 객체 생성 시 **Heap**에 생성, 객체가 소멸할 때 제거 | 블록이 실행될 때 **Stack**에 생성, 블록을 벗어나면 소멸 |
>   | 초기화 | 기본값(0, false, null)으로 **자동 초기화** | 자동 초기화되지 않음, 사용 전 **반드시 초기화** |
>   | 접근 제어자 | `private`, `public` 등 사용 가능 | 사용 불가 |
>
> - 💡 레퍼런스 필드는 `.`을 두 번 써서 접근한다: `r.origin.x = 3;`. 이렇게 객체가 다른 객체를 필드로 가지는 구조를 **포함 관계(Composition)**라고 한다. (실습 클래스2 1번 Circle + Point, 과제 클래스2 4번 Rectangle + Point)
> - ⚠ 슬라이드의 스마트 따옴표(`“ ”`)는 그대로 쓰면 컴파일 오류가 난다. 위 코드는 일반 따옴표로 바꿨다.
> - ⚠ 슬라이드 5처럼 `public class MyPoint`와 `public class MyRectangle`을 한 파일에 쓸 수는 없다. 각자 다른 파일(MyPoint.java, MyRectangle.java)에 있다는 뜻으로 읽어야 한다.

## 3. 메소드 정의 및 호출

- 메소드는 객체가 제공하는 기능에 이름을 붙인 것이다.
- 그 기능을 구현하는 데 필드 말고 추가로 필요한 데이터는 **인수**로 전달한다.

```java
반환형 메소드명 ( 인수선언1, ..., 인수선언n ) {
    메소드본체;
}
```

```java
class MyTest {
    ...
    int f(int x, double y) { ... }  // 반환되는 값이 없는 경우 void
    ...
}

MyTest ob = new MyTest();
int res = ob.f(3, 4.5);   // 호출
```

- **실인자(actual argument)**: 실인수, 실매개변수(actual parameter). 메소드를 호출할 때 넘겨주는 값이다. → `3`, `4.5`
- **형식인자(formal argument)**: 형식인수, 형식매개변수. 실인수에 대응하는, 메소드 정의 부분에 있는 변수다. → `x`, `y`

```
호출     ob.f( 3 , 4.5 )        ← 실인자
              │    │
정의   int f(int x, double y)   ← 형식인자 (x = 3, y = 4.5 로 복사됨)
```

> 참고:
> - 📝 **필기 (퀴즈 1번):** 메서드의 결과값을 반환하려면 `return 반환값;`을 쓴다.
> - 💡 반환형이 `void`가 아니면 모든 실행 경로에서 `return`으로 값을 돌려줘야 한다. `void` 메소드에서는 `return;`만 써서 중간에 끝낼 수 있다. (과제 클래스1 4번 Stopwatch의 `start()`/`stop()`)
> - ⚠ 슬라이드의 `Int res = ob.f(3, 4.5);`는 `int`의 오타다.

## 4. [실습] 학생 성적 클래스 정의하기

- 학생 3명의 이름, 학번, 국어·영어·수학 점수를 `Student` 클래스로 묶는다.
- 과목별 평균과 전체 평균을 계산한다.

```java
// StudentScore.java 파일
public class StudentScore {
    public static void main(String[] args) {
        int korSum = 0, engSum = 0, mathSum = 0;
        double totalSum = 0.0, korAvg, engAvg, mathAvg, totalAvg;
        Student [] students = new Student[3];
        students[0] = new Student();
        students[0].setInfo("bmkim1", 2016001, 70, 80, 90);
        students[1] = new Student();
        students[1].setInfo("bmkim2", 2016002, 60, 70, 80);
        students[2] = new Student();
        students[2].setInfo("bmkim3", 2016003, 50, 60, 70);
        for(int i=0; i < students.length; i++) {
            System.out.println(students[i].getInfo());
            korSum += students[i].kor;
            engSum += students[i].eng;
            mathSum += students[i].math;
            totalSum += students[i].getAverage();
        }
        korAvg = korSum / (double) students.length;
        engAvg = engSum / (double) students.length;
        mathAvg = mathSum / (double) students.length;
        totalAvg = totalSum / (double) students.length;
        System.out.println("국어 평균 : " + korAvg);
        System.out.println("영어 평균 : " + engAvg);
        System.out.println("수학 평균 : " + mathAvg);
        System.out.println("전체 평균 : " + totalAvg);
    }
}

class Student {
    String sname;
    int sid, kor, eng, math;
    void setInfo(String name, int id, int k, int e, int m) {
        sname = name;
        sid = id;
        kor = k; eng = e;
        math = m;
    }
    double getAverage() {
        return (kor + eng + math)/3.0;
    }
    String getInfo() {
        return sname +", "+ sid +", "+ kor +", "+ eng + ", " + math;
    }
}
```

```
bmkim1, 2016001, 70, 80, 90
bmkim2, 2016002, 60, 70, 80
bmkim3, 2016003, 50, 60, 70
국어 평균 : 60.0
영어 평균 : 70.0
수학 평균 : 80.0
전체 평균 : 70.0
```

> 참고:
> - 💡 `new Student[3]`은 레퍼런스를 담을 **칸 3개**만 만든다. 각 칸은 처음에 `null`이다. `students[0] = new Student();`처럼 칸마다 객체를 따로 만들어 넣어야 한다. 객체를 넣지 않고 `students[0].setInfo(...)`를 부르면 `NullPointerException`이 난다.
> - 💡 `(kor + eng + math)/3`으로 쓰면 정수 나눗셈이라 소수점이 버려진다. `3.0`이나 `(double)`로 실수 나눗셈을 만든다.
> - ⚠ 슬라이드 첫 줄의 주석 `// StudentInfo.java 파일`은 잘못 적은 것이다. public class 이름이 `StudentScore`이므로 파일 이름도 `StudentScore.java`여야 한다.
> - 이 예제는 8-2(this, static), 8-3(private + getter)에서 차례로 고쳐 나간다.
