## 1. 배열 복사: 레퍼런스 복사 (공유)

아래 코드는 배열 변수에 저장된 **레퍼런스가 복사**된다. 그래서 두 변수가 **같은 배열 객체를 공유**한다.

```java
public static void main(String[] args) {
    int[] myArray1 = new int[] {1, 2, 3};
    int[] myArray2 = myArray1;   // 레퍼런스가 복사되어 배열 공유
    myArray2[1] = 0;
    System.out.println(myArray1[1]);
}
```

```
=== 결과 ===
0
```

```
myArray1 ──┐
           ├──▶ [ 1 | 0 | 3 ]     ← 배열 객체는 1개
myArray2 ──┘
```

> 참고:
> - 배열 변수에는 배열 자체가 아니라 **배열이 있는 곳(레퍼런스)** 이 들어 있다. (5-1 2절 그림)
> - `myArray2 = myArray1`은 그 레퍼런스(주소)만 복사한다. 같은 배열을 가리키는 이름이 하나 더 생길 뿐이다.
> - 그래서 `myArray2[1]`을 바꾸면 `myArray1[1]`도 바뀐 것처럼 보인다. 사실은 **같은 칸**이다.
> - 📝 **필기 (퀴즈 5번):** `int[] myarray2 = myarray1;`로 하면 myarray1 → 레퍼런스 1 (3,1,2,3), myarray2 → 레퍼런스 1 (3,1,2,3)이 된다. 따라서 값을 바꾸면 **둘 다** 레퍼런스 1 (3,0,2,3)을 보게 된다.

## 2. 배열 복사: `clone()` (배열 자체를 복사)

배열 자체를 복사하고 싶으면 배열 객체의 **`clone` 메소드**를 사용한다.

```java
public static void main(String[] args) {
    int[] myArray1 = new int[] {1, 2, 3};
    int[] myArray2 = myArray1.clone();
    myArray2[1] = 0;
    System.out.println(myArray1[1]);
}
```

```
=== 결과 ===
2
```

```
myArray1 ──▶ [ 1 | 2 | 3 ]     ← 원본 그대로
myArray2 ──▶ [ 1 | 0 | 3 ]     ← 새로 만들어진 복사본
```

> 참고:
> - `clone()`은 **같은 크기의 새 배열**을 만들고 값을 하나씩 복사한 뒤, 새 배열의 레퍼런스를 돌려준다.
> - 📝 **필기 (퀴즈 5번):** myarray1 → 레퍼런스 1 (3,1,2,3). `.clone()`을 하면 myarray2 → **레퍼런스 2** (3,1,2,3). 값을 바꾸면 myarray2 → 레퍼런스 2 (3,0,2,3)이고, myarray1 → 레퍼런스 1 (3,1,2,3) 값은 유지된다.
> - ⚠ 퀴즈 4·5번에서 처음에 이 둘을 **반대로** 답했다. "clone을 하면 레퍼런스 주소가 복사된다"고 썼는데, 레퍼런스가 복사되는 것은 `=` 대입이고 **clone은 값이 복사된 새 배열**이다.
> - 💡 이 외에도 반복문으로 직접 복사하기(실습 배열(2) 1번), `Arrays.copyOf(원본, 길이)`, `System.arraycopy(...)` 방법이 있다.

## 3. 다차원 배열

일차원 배열과 사용법은 같고, **차원만 늘리면** 된다.

```java
// 2차원 배열 변수 선언
int [][] myArray2d;

// 2차원 배열 객체 생성 및 초기화
myArray2d = new int[][] { {1, 0, 3}, {6, 9, 12} };

// 3차원 배열 변수 선언 및 배열 객체 생성
int [][][] myArray3d = new int[2][3][2];

// 2차원 및 3차원 배열 객체 접근
int x = myArray3d[1][2][0] + myArray2d[0][1];
```

> 참고:
> - `myArray2d`는 2행 3열이다. `myArray2d[행][열]` 순서로 접근한다. `myArray2d[0][1]`은 0행 1열의 `0`이다.
> - `myArray3d`는 2 × 3 × 2 = 12칸이고, 모두 기본값 0이다. 그래서 `x = 0 + 0 = 0`이다.
> - 💡 초기화 값을 줄 때는 1차원처럼 **크기를 쓰면 안 된다.** `new int[2][3] {{...}}` ❌

## 4. 자바의 다차원 배열 구조

- 자바에서 다차원 배열은 **일차원 배열을 이용하여** 구현한다.
- 자바는 **행 개수 크기의 1차원 배열**을 만들고, 그 배열의 원소에 **각 행에 해당하는 1차원 배열의 레퍼런스**를 저장한다.

```
myArray2d ──▶ [ ● ]──▶ [ 1 | 0 | 3  ]    ← 0행 (int[] 하나)
              [ ● ]──▶ [ 6 | 9 | 12 ]    ← 1행 (int[] 하나)
               ↑
         "행 배열" : int[] 의 레퍼런스 2개를 담는 1차원 배열
```

> 참고:
> - 그래서 `myArray2d.length`는 **행 개수**(2)이고, `myArray2d[0]`은 **0행 전체(int[])** 이다. `myArray2d[0].length`는 0행의 **열 개수**(3)이다.
> - 📝 **필기 (퀴즈 6번):**
>   - 2차원 배열은 자바에서 **1차원 배열의 레퍼런스를 값으로 가지는 배열**을 가지는 구조다. 플렉서블하지만 느리다.
>   - `int[]`가 1차원 배열을 가리키고, 그것을 가리키는 배열을 `int[][]`로 선언하는 것이다.
>   - 자바에서는 **들쭉날쭉하게** 행마다 열의 개수를 다르게 선언할 수 있다.
>   - C에서는 1차원 배열이 **연속적으로 나열된** 구조다. 속도는 월등히 빠르다. C에서는 열의 개수가 행마다 달라서는 안 된다.
>   - 💡 보충: C의 2차원 배열은 정방행렬(n × n)만 되는 것이 아니라 **모든 행의 길이가 같은 직사각형(R × C)** 이면 된다. "정방행렬만 가능"보다 "직사각형만 가능, 행마다 길이가 다를 수 없다"가 정확하다.
> - 📝 **필기 (퀴즈 8번):** data는 r행들의 값을 의미하고, 그 값 하나하나는 1차원 배열에 매핑되어 있다. `data[r]`이라고 하면 r행의 값 하나 그 자체가 1차원 배열을 의미한다. 즉 **`data[r].length`라고 하면 열의 크기**를 알 수 있다.
> - 💡 "느리다"는 말의 뜻: 원소 하나에 접근하려면 행 배열에서 레퍼런스를 꺼내고, 그 레퍼런스를 따라 한 번 더 가야 한다. 또 각 행이 메모리 여기저기에 흩어질 수 있다.

## 5. 다차원 배열과 `clone()`

위와 같은 구조이기 때문에 2차원 배열에 `clone` 메소드를 쓰면 **행 배열만 복사되고, 각 행은 공유**된다.

```java
myArray2d2 = myArray2d.clone();
```

```
myArray2d ──▶ [ ● ]──▶ [ 1 | 0 | 3  ] ◀──[ ● ] ◀── myArray2d2
              [ ● ]──▶ [ 6 | 9 | 12 ] ◀──[ ● ]

  행 배열(왼쪽, 오른쪽)은 2개로 복사됨  /  실제 행(int[])은 1벌을 공유
```

- 원소까지 복사하려면 **각 행의 배열도 일일이** 복사해 주어야 한다.

```java
int[][] copy = new int[myArray2d.length][];
for (int i = 0; i < myArray2d.length; i++)
    copy[i] = myArray2d[i].clone();   // 행마다 clone
```

> 참고:
> - 💡 `clone()`이 복사하는 것은 배열의 **원소 값**이다. 2차원 배열에서 바깥 배열의 원소 값은 "각 행의 레퍼런스"다. 그래서 레퍼런스만 복사되고 행은 공유된다. 이것을 **얕은 복사(shallow copy)** 라고 한다. 위의 반복문처럼 안쪽까지 복사하는 것을 **깊은 복사(deep copy)** 라고 한다.
> - 💡 `myArray2d2[0][1] = 100;`으로 바꾸면 `myArray2d[0][1]`도 100이 된다. 반대로 `myArray2d2[0] = new int[]{7, 7, 7};`처럼 **행 자체를 바꾸면** 원본은 영향을 받지 않는다. 행 배열은 따로 복사되었기 때문이다. → [`examples/ArrayCopy.java`](../examples/ArrayCopy.java)에서 확인

## 6. Jagged 배열 (들쭉날쭉한 배열)

각 행의 길이가 다른 배열을 만들 수 있다. 이것을 **Jagged 배열**이라고 부른다. 배열 변수를 선언하고 초기화할 때 일차원 배열의 크기를 달리한다.

```java
int[][] jagged = { new int[] {1, 0, 3}, new int[] {6, 9} };
```

또 다른 방법:

```java
int [][] jagged;
jagged = new int[2][];             // 2개의 행을 생성
jagged[0] = new int[]{1, 0, 3};    // 첫 번째 행 배열 객체 생성
jagged[1] = new int[]{6, 9};       // 두 번째 행 배열 객체 생성
```

```
jagged ──▶ [ ● ]──▶ [ 1 | 0 | 3 ]
           [ ● ]──▶ [ 6 | 9 ]
```

> 참고:
> - `new int[2][]`는 행 배열만 만든다. 이 시점에 `jagged[0]`, `jagged[1]`은 `null`이다. (5-1 5절 레퍼런스형 배열과 같은 이야기. 각 행은 `int[]` **객체**이기 때문)
> - 💡 열 크기만 비우는 것은 되지만 **행 크기를 비우는 것은 안 된다.** `new int[][3]` ❌
> - 📝 **필기 (퀴즈 7번):** `int[][] data = new int [][] { {1,2,3}, {6,5}, {7,4,5,8} };` 자바에서는 들쭉날쭉한 2차원 배열 선언이 가능하다.
> - 💡 `{ {1, 0, 3}, {6, 9} }`처럼 `new int[]` 없이 써도 같은 jagged 배열이 된다.

## 7. 다차원 배열 출력: `array.length`와 `array[i].length`

```java
public class MultiDimensionTest {
    public static void main(String[] args) {
        int[][] array = {{62, 17, 4, 64}, {18, 96, 29, 5}, {6, 3, 6, 5}};

        for (int i = 0; i < array.length; i++) {            // 다차원 배열의 행 개수
            System.out.println();
            for (int j = 0; j < array[i].length; j++) {     // i 행의 1차원 배열 크기
                System.out.print(array[i][j] + " ");
            }
        }
        System.out.println();
    }
}
```

```
=== 결과 ===

62 17 4 64
18 96 29 5
6 3 6 5
```

> 참고:
> - 바깥 for는 **행**(`array.length` = 3), 안쪽 for는 **열**(`array[i].length` = 4)을 담당한다.
> - 안쪽 조건을 숫자 4나 `array[0].length`가 아니라 **`array[i].length`** 로 쓰면 jagged 배열도 그대로 출력할 수 있다.
> - 💡 줄바꿈을 행 출력 **앞**에 하므로 첫 줄이 빈 줄이고, 마지막에 `println()`을 한 번 더 한다. 보통은 안쪽 for **뒤**에 `println()`을 두는 형태(8절)를 더 많이 쓴다.
> - 📝 실습 배열(2) 6번 필기(AI 설명): 바깥쪽 `i`는 행(row)을 담당하고, 안쪽 `j`는 열(column)을 담당한다. 여기서 중요한 것은 **for 문을 두 개** 사용하는 것이다.

## 8. [실습] 행렬 덧셈

```java
import java.util.Random;

public class MatrixAdd {
    public static void main(String[] args) {
        int [][] m1 = new int[3][3];
        int [][] m2 = new int[3][3];
        int [][] m3 = new int[3][3];
        Random rnd = new Random();

        // 행렬 초기화
        for (int i = 0; i < m1.length; i++) {
            for (int j = 0; j < m1[i].length; j++) {
                m1[i][j] = rnd.nextInt(100);
                m2[i][j] = rnd.nextInt(100);
            }
        }

        // 행렬 덧셈
        for (int i = 0; i < m3.length; i++) {
            for (int j = 0; j < m3[i].length; j++) {
                m3[i][j] = m1[i][j] + m2[i][j];
            }
        }

        // m1 행렬 출력
        for (int i = 0; i < m1.length; i++) {
            for (int j = 0; j < m1[i].length; j++) {
                System.out.print(m1[i][j] + " ");
            }
            System.out.println();
        }
        System.out.println();

        // m2 행렬 출력
        for (int i = 0; i < m2.length; i++) {
            for (int j = 0; j < m2[i].length; j++) {
                System.out.print(m2[i][j] + " ");
            }
            System.out.println();
        }
        System.out.println("================");

        // m3 행렬 출력
        for (int i = 0; i < m3.length; i++) {
            for (int j = 0; j < m3[i].length; j++) {
                System.out.print(m3[i][j] + " ");
            }
            System.out.println();
        }
    }
}
```

```
=== 결과 (슬라이드 화면, 난수라 매번 다름) ===
31 99 99
84 64 97
17 73 35

18 83 23
86 48 22
51 46 22
================
49 182 122
170 112 119
68 119 57
```

> 참고:
> - 행렬 덧셈은 **같은 위치끼리** 더한다. `m3[i][j] = m1[i][j] + m2[i][j]` (예: 31 + 18 = 49)
> - `rnd.nextInt(100)`은 **0 이상 100 미만**(0 ~ 99)의 정수다.
> - 💡 같은 "행렬 출력" 코드가 세 번 반복된다. 메소드로 빼면 `printMatrix(m1);`처럼 한 줄로 줄일 수 있다. (과제 배열(2) 3·4번의 리팩터링 코드가 이렇게 했다.)
> - 💡 행렬 곱셈은 덧셈과 달리 **같은 위치끼리 곱하는 것이 아니다.** 과제 배열(2) 4번 참고.
