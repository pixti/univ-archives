## 1. 배열 정렬: `Arrays.sort`

- 정렬 방법은 다양하고, 방법에 따라 코드도 다양하다.
- 여기서는 `java.util.Arrays` 클래스의 **정적 메소드 `sort`** 를 사용한다.

```java
import java.util.Arrays;

public class ArrayTest {
    public static void main(String[] args) {
        int[] array = {1, 5, 3, 2, 4};

        for (int e : array)   // 정렬 전 원소 출력
            System.out.print(e + " ");

        Arrays.sort(array);   // 배열 정렬

        for (int e : array)   // 정렬 후 원소 출력
            System.out.print(e + " ");
    }
}
```

```
=== 결과 ===
1 5 3 2 4 1 2 3 4 5
```

> 참고:
> - **정적(static) 메소드**는 객체를 만들지 않고 `클래스이름.메소드()`로 부른다. `Math.random()`, `Math.sqrt()`와 같은 방식이다.
> - `Arrays.sort`는 **원본 배열 자체를 바꾼다.** 정렬된 새 배열을 돌려주는 것이 아니다. (반환형 void)
> - `for (int e : array)`는 4-4에서 배운 **foreach**다. 인덱스 없이 원소를 처음부터 끝까지 하나씩 `e`에 꺼낸다.
> - 💡 줄바꿈이 없어 정렬 전과 후가 한 줄에 이어서 찍힌다. 사이에 `System.out.println();`을 넣으면 보기 좋다.
> - ⚠ 슬라이드의 오타와 오류를 고쳤다: "졍렬" → "정렬", 둥근 따옴표 `“ “` → `" "`, 두 번째 출력의 `e + ““`(공백 없음) → `e + " "`.
> - 💡 `Arrays.toString(array)`를 쓰면 `[1, 2, 3, 4, 5]` 형태로 한 번에 출력할 수 있다. (실습에서 자주 사용)

## 2. 내림차순 정렬 (int 배열)

- 앞의 예시는 **오름차순**이다.
- 기본형 배열을 내림차순으로 정렬해 주는 메소드는 따로 없다. **오름차순 정렬 후 역순으로 재정렬**한다.

```java
int [] a = new int[]{4, 2, 3, 1, 5};
Arrays.sort(a);
for (int i = 0; i < a.length / 2; i++) {   // a.length 는 a배열의 크기를 알려줌
    int temp = a[i];
    a[i] = a[a.length - (i + 1)];
    a[a.length - (i + 1)] = temp;
}
```

```
정렬 후      [1, 2, 3, 4, 5]
i=0 교환     [5, 2, 3, 4, 1]    a[0] ↔ a[4]
i=1 교환     [5, 4, 3, 2, 1]    a[1] ↔ a[3]
(a[2]는 가운데라 그대로, 5/2 = 2 번만 반복)
```

슬라이드 오른쪽에는 두 변수의 값을 **교환(swap)** 하는 방법이 그려져 있다.

```java
// ❌ 잘못된 교환
int a = 0, b = 3;
a = b;     // a = 3   ← 원래 a 값 0 이 사라짐
b = a;     // b = 3   → 둘 다 3

// ✅ 올바른 교환 (임시 변수)
int a = 0, b = 3;
int tmp = a;   // tmp = 0
a = b;         // a = 3
b = tmp;       // b = 0
```

> 참고:
> - **`a.length / 2`까지만** 반복하는 이유: 끝까지 반복하면 앞쪽 절반에서 바꾼 것을 뒤쪽 절반에서 **한 번 더 바꿔서 원래대로** 돌아간다.
> - `a.length - (i + 1)`은 `a.length - 1 - i`와 같다. i번째와 **대칭인 위치**다.
> - 📝 **필기 (실습 배열(1) 4번):** 배열의 대칭성을 이용한다. `[7, 6, 5, 4, 3]`이라면 중앙 5를 기준으로 0번째 - 4번째, 1번째 - 3번째끼리 대칭이다. 일반화하면 **i번째 - (배열길이 - i - 1)번째** 끼리 대칭이다. 스왑은 `temp = x; x = y; y = temp;`
> - ⚠ 슬라이드의 `int a=0; b=3;`은 문법 오류다. `b`가 선언되지 않았다. `int a = 0, b = 3;`처럼 쉼표로 이어 써야 한다.
> - 💡 그림 왼쪽의 "잘못된 교환"은 3주차부터 반복된 이야기다. 대입하면 **이전 값은 사라진다.** 그래서 덮어쓰기 전에 다른 곳에 옮겨 두어야 한다.

## 3. 내림차순 정렬 (객체 배열)

레퍼런스형 배열(객체 배열)은 `sort` 메소드에 **Comparator 객체를 인수로** 넘겨 내림차순으로 정렬할 수 있다.

```java
String[] b = {"aa", "ff", "dd", "bb"};
Arrays.sort(b, Collections.reverseOrder());
```

```
=== 결과 ===
[ff, dd, bb, aa]
```

> 참고:
> - `Collections`는 `java.util.Collections`다. `import java.util.Collections;`가 필요하다.
> - 💡 `Collections.reverseOrder()`는 "**반대 순서로 비교**하는 규칙(Comparator)"을 만들어 준다. sort는 이 규칙에 따라 정렬한다.
> - 💡 `int[]`에는 이 방법을 쓸 수 없다. Comparator는 **객체**끼리 비교하는 규칙이라 기본형 `int`에는 적용되지 않는다. 그래서 2번처럼 뒤집거나, `Integer[]`(int를 감싼 객체 배열)로 만들어야 한다.
> - 💡 문자열은 사전 순(정확히는 유니코드 순)으로 비교된다.

## 4. [실습] 학생 성적 정렬

```java
import java.util.Arrays;
import java.util.Scanner;

public class ScoreProcessing {
    public static void main(String[] args) {
        int val, cnt = 0, sum = 0;
        int [] array = new int[100];

        Scanner sc = new Scanner(System.in);
        System.out.println("0과 100 사이의 값을 입력 (그외 값 종료) : ");
        val = sc.nextInt();
        while (val >= 0 && val <= 100) {
            array[cnt] = val;
            cnt = cnt + 1;   // 입력 정수의 개수 세기
            System.out.println("0과 100 사이의 값 입력 (그외 값 종료) : ");
            val = sc.nextInt();
        }

        System.out.print("정렬 전 성적 : ");
        for (int i = 0; i < cnt; i++) System.out.print(array[i] + " ");
        System.out.println();

        Arrays.sort(array, 0, cnt - 1);   // 범위지정하지 않으면 실행결과 모두 0

        System.out.print("정렬 후 성적 : ");
        for (int i = 0; i < cnt; i++) System.out.print(array[i] + " ");
        System.out.println();
        sc.close();
    }
}
```

슬라이드에는 실행 화면이 두 개 있다. (입력 50, 40, 30, 70, -1)

```
=== Arrays.sort(array); 로 했을 때 ===
정렬 전 성적 : 50 40 30 70
정렬 후 성적 : 0 0 0 0

=== Arrays.sort(array, 0, cnt-1); 로 했을 때 ===
정렬 전 성적 : 50 40 30 70
정렬 후 성적 : 30 40 50 70
```

> 참고: **범위를 지정하지 않으면 결과가 모두 0인 이유**
> - 배열 크기는 100인데 값은 4개만 들어 있다. 나머지 96칸은 **기본값 0**이다.
> - `Arrays.sort(array)`는 100칸 전체를 정렬한다. 0이 96개나 되니 앞쪽 96칸이 모두 0이 되고, 입력한 값은 맨 뒤 `array[96] ~ array[99]`로 밀려난다.
> - 출력은 `cnt`(4)개까지만 하므로 `0 0 0 0`이 보인다.
> - 그래서 `Arrays.sort(배열, 시작, 끝)`으로 **값이 들어 있는 부분만** 정렬한다.
>
> - ⚠ **`cnt - 1`은 틀렸다.** `Arrays.sort(a, fromIndex, toIndex)`의 `toIndex`는 **포함하지 않는다(exclusive).** `0, cnt-1`이면 `array[0] ~ array[cnt-2]`만 정렬되고 **마지막 값은 정렬에서 빠진다.**
>   - 화면의 예는 마지막 입력 70이 우연히 가장 커서 맞게 나왔다.
>   - 입력이 50, 40, 70, 30이면 `30 40 50 70`이 아니라 `40 50 70 30`이 나온다.
>   - 다음 실습(5절)의 슬라이드에서는 `Arrays.sort(array, 0, cnt)`로 고쳐져 있다. → [`examples/ScoreSort.java`](../examples/ScoreSort.java)는 `cnt`로 고쳤다.
> - 💡 `for (int i = 0; i < cnt; i++)`처럼 "시작 포함, 끝 미포함"은 자바 전체의 관례다. `substring(시작, 끝)`도 같다. 범위가 `[0, cnt)`이면 원소의 개수가 정확히 `cnt - 0 = cnt`개가 된다.
> - 💡 변수 `sum`은 선언만 하고 쓰이지 않는다. (앞 실습 코드를 고쳐 쓰다 남은 것)

## 5. 배열 탐색: `Arrays.binarySearch`

- 탐색 방법도 다양하고, 방법에 따라 코드도 다양하다.
- `java.util.Arrays`가 **정적 메소드 `binarySearch`** 를 제공한다.
- 다양한 배열 객체에 대해 동작하도록 **중복정의(overloading)** 되어 있다.
- 원하는 값(키)이 존재하면 그 위치의 **첨자 값을 반환**한다.

```java
import java.util.Arrays;

public class BinarySearchTest {   // int idx = Arrays.binarySearch(배열, 키) 형태로 쓴다
    public static void main(String[] args) {
        int [] a = new int[]{3, 2, 1, 4, 5};
        Arrays.sort(a);
        int i = Arrays.binarySearch(a, 3);
        System.out.println(i);
        i = Arrays.binarySearch(a, 0);   // 찾는 값이 없음 -1 출력
        System.out.println(i);
        i = Arrays.binarySearch(a, 6);   // 찾는 값이 없음 -6 출력
        System.out.println(i);
    }
}
```

```
=== 결과 ===
2
-1
-6
```

> 참고:
> - **이진 탐색(binary search)** 은 정렬된 배열에서 가운데 값과 비교해 절반씩 범위를 줄여 가며 찾는다. 그래서 **반드시 먼저 정렬**해야 한다. 정렬하지 않은 배열에 쓰면 결과를 믿을 수 없다.
> - 정렬 후 `a = [1, 2, 3, 4, 5]`이므로 3의 위치는 **2**다.
> - 💡 **값이 없을 때 반환값 = `-(삽입 위치) - 1`**
>   - 삽입 위치는 "그 값이 있었다면 들어갔을 자리"다.
>   - 0은 맨 앞(삽입 위치 0)에 들어가므로 `-(0) - 1 = -1`.
>   - 6은 맨 뒤(삽입 위치 5)에 들어가므로 `-(5) - 1 = -6`.
>   - 그냥 `-삽입위치`로 하면 삽입 위치가 0일 때 0이 되어 "0번째에 있음"과 구분이 안 된다. 그래서 1을 더 뺀다. 결국 **음수면 "없음"** 이라고 판단하면 된다.
> - 💡 **중복정의(overloading):** 이름은 같고 매개변수가 다른 메소드가 여러 개 있다는 뜻이다. `binarySearch(int[], int)`, `binarySearch(double[], double)`, `binarySearch(int[], 시작, 끝, int)` 등이 모두 있다. `println`도 같은 방식이다.
> - ⚠ 슬라이드의 세 번째 대입 `I = ...`은 대문자 `I`라서 컴파일 오류다. (선언되지 않은 변수) 소문자 `i`로 고쳤다.
> - 💡 값이 중복으로 있으면 그중 **어느 위치가 반환될지 보장되지 않는다.**

## 6. [실습] 학생 성적 정렬 및 검색하기

```java
import java.util.Arrays;
import java.util.Scanner;

public class ConditionOperation {
    public static void main(String[] args) {
        int val, cnt = 0, sum = 0;
        int [] array = new int[100];

        Scanner sc = new Scanner(System.in);
        System.out.println("0과 100 사이의 값을 입력 (그외 값 종료) : ");
        val = sc.nextInt();
        while (val >= 0 && val <= 100) {
            array[cnt] = val;
            cnt = cnt + 1;   // 입력 정수의 개수 세기
            System.out.println("0과 100 사이 값 입력 (그외 값 종료) : ");
            val = sc.nextInt();
        }

        Arrays.sort(array, 0, cnt);   // 마찬가지로 시작과 끝을 지정

        System.out.print("정렬 후 성적 : ");
        for (int i = 0; i < cnt; i++) System.out.print(array[i] + " ");
        System.out.println();

        System.out.print("찾고자 하는 성적을 입력하세요 : ");
        val = sc.nextInt();

        int i = Arrays.binarySearch(array, 0, cnt, val);
        if (i < 0)
            System.out.println("성적이 존재하지 않습니다.");
        else
            System.out.println("성적은 " + (i + 1) + " 번째에 ");
        sc.close();
    }
}
```

슬라이드의 실행 화면(입력 50, 40, 30, 70, -1, 검색 40):

```
=== 결과 (슬라이드 화면) ===
정렬 후 성적 : 30 40 50 70
찾고자 하는 성적을 입력하세요 : 40
원하는 성적은 배열의 2 번째에 존재합니다.
```

> 참고:
> - 정렬과 마찬가지로 탐색도 `binarySearch(배열, 시작, 끝, 키)`로 **값이 있는 부분만** 탐색한다. 범위를 안 주면 뒤쪽 0들까지 탐색 대상이 된다.
> - 반환값은 **인덱스(0부터)** 이고, 사람에게 보여 줄 때는 `i + 1`로 "몇 번째"(1부터)로 바꾼다.
> - ⚠ 실행 화면 속 이클립스 코드는 `binarySearch(array, 0, cnt-1, val)`로 되어 있다. 4절과 같은 실수다. 이 코드로는 **마지막(가장 큰) 성적 70을 검색하면 "존재하지 않습니다"** 가 나온다. 슬라이드 본문 코드(`cnt`)가 맞다.
> - ⚠ 화면의 안내 문구("원하는 성적은 배열의 2 번째에 존재합니다.")는 본문 코드("성적은 2 번째에 ")와 다르다. 예제 파일에서는 문장이 끝나도록 본문 코드에 "존재합니다."를 붙였다.
> - 💡 sort, binarySearch 모두 **범위 버전**이 있다. 배열을 "최대 크기로 만들고 개수는 따로 센다"(5-1 7절) 방식과 함께 쓸 때 꼭 필요하다.
