## 1. [실습] 사용자 이름을 입력받아 인사말 출력하기

1. 이클립스에서 **File → New → Java Project**를 선택한다. 프로젝트 이름은 `SayHelloTest`로 한다.
2. 프로젝트 탐색기(Project Explorer)에서 프로젝트를 우클릭하고 **New → Class**를 선택한다.
3. 클래스 이름(`SayHello`)을 입력하고, main 메소드를 자동으로 만드는 옵션을 체크한다.

```java
import java.util.Scanner;   // ← 이 줄이 없으면 컴파일 에러!

public class SayHello {
    public static void main(String[] args) {
        System.out.println("이름 입력 >> ");
        Scanner sc = new Scanner(System.in);
        String name = sc.next();
        sc.close();
        // + 기호로 긴 문자열 연결
        String helloMessage = "안녕하세요. " + name +
                " 님, 자바 세계에 오실 것을 축하드립니다.";
        System.out.println(helloMessage);
    }
}
```

- `import`를 쓰지 않으면 Scanner의 패키지를 알 수 없어 **컴파일 에러**가 난다(`Scanner cannot be resolved to a type`).
- 맨 윗줄에 `import java.util.Scanner;`를 추가하면 해결된다.
- 이클립스에서는 빨간 줄 위에 마우스를 올리면 해결 창이 뜬다. 맨 위의 해결책 **Import 'Scanner' (java.util)** 를 고르면 자동으로 추가된다.
  - 단축키 **Ctrl + Shift + O**로 필요한 import를 한 번에 정리할 수도 있다.
- 빨간 줄이 사라지면 **File → Save All**로 저장한 뒤 실행한다.

> 📝 **필기 (실습 수식 1번):** import 없이 Scanner를 쓰면 빨간 줄이 생긴다. 마우스를 올리면 나오는 빠른 수정 목록에서 맨 위의 **"'Scanner' (java.util) 가져오기"** 를 고르면 맨 위에 `import java.util.Scanner;`가 자동으로 추가된다.
> → [`practice/expressions/BoxVolume.java`](../practice/expressions/BoxVolume.java)

> ⚠ 슬라이드 코드의 두 번째 문자열은 `“`(전각 따옴표)로 시작해서 그대로는 컴파일되지 않는다. 반각 `"`로 고쳤다.

## 2. 자료형 변환 (Type Casting)

### 자동 형변환 (묵시적, Promotion)

- 대입할 때는 왼쪽 변수의 자료형과 오른쪽 값(변수)의 자료형이 일치해야 한다.
- 다만 **오른쪽 자료형이 왼쪽보다 작으면** 대입이 허용된다. 컴파일러가 작은 자료형의 값을 큰 자료형으로 **자동 변환**한다.

```java
int x;
x = 6;      // 자료형 일치, OK
x = 3.7;    // ✗ 자료형 불일치. 우측(double)이 더 크다
double d;
d = 3;      // OK. int 3 → double 3.0 자동 변환
```

### 강제 형변환 (명시적, Casting)

- 왼쪽 자료형이 오른쪽보다 작으면 정보가 손실될 수 있어 허용하지 않는다.
- 손실이 생겨도 저장하고 싶다면 `(자료형)`으로 **강제 형변환**한다.

```java
double d;
int x = 10;
d = x;              // OK
x = d;              // ✗ 자료형 불일치 오류
x = (int) 3.14;     // 강제 형변환. x 에 3 이 대입된다 (소수점 이하 버림)
```

### 자동 형변환이 일어나는 방향

```
byte → short ─┐
              ├→ int → long → float → double
       char ──┘
```

> 참고:
> - `long`(8 byte)이 `float`(4 byte)으로 자동 변환되는 이유는 float이 표현할 수 있는 **범위**가 더 크기 때문이다. 대신 정밀도는 손실될 수 있다.
> - `byte`/`short`와 `char` 사이에는 자동 변환이 없다. `char`는 부호가 없기 때문이다.

> 💡 **과제 Test1 풀이 중:**
> - `int i = d;`처럼 double을 int에 넣으면 에러이므로 `(int) d`로 강제 형변환해야 한다.
> - `'abc'`처럼 작은따옴표에 여러 글자를 넣을 수 없다. 문자열은 `"abc"`로 쓴다.
> → [`assignment/variables/Test1.java`](../assignment/variables/Test1.java)

### 자동 형변환 예제

```java
public class Assignment {
    public static void main(String[] args) {
        char c = '한';
        System.out.println("문자 : " + c);
        int code = c;                       // 자동 형변환 (char → int)
        System.out.println("유니코드 : " + Integer.toHexString(code));
        int i = 0xd55d;
        char c2 = (char) i;                 // 강제 형변환 필요 (int → char)
        System.out.println("문자 : " + c2);
    }
}
```

```
== 결과 ==
문자 : 한
유니코드 : d55c
문자 : 핝
```

- 슬라이드의 `char c2 = i;`는 컴파일 에러다. `char c2 = (char) i;`로 바꿔야 한다.
- `'한'`의 유니코드는 `d55c`이고, 그다음 코드 `d55d`는 `'핝'`이다.

## 3. 사용자 정의 자료형

- 자바에서는 필요할 때 자료형을 추가로 정의해서 쓸 수 있다. 이것이 **클래스**다.
- 변수를 선언하면 객체가 생성되는 것이 아니다. 객체를 조작할 수 있는 값(**레퍼런스**)을 저장할 공간만 확보된다.
- 그래서 객체를 다루려면 레퍼런스 변수를 선언한 뒤 반드시 `new`로 **객체를 생성**해야 한다.

```java
클래스명 변수명 = new 클래스명(필요한 값들);   // 선언과 동시에 생성

클래스명 변수명;                              // 그냥 사용하면 오류 (객체가 없음)
변수명 = new 클래스명(필요한 값들);            // 선언 후 생성
```

```java
// 예시: 지금까지 쓴 Scanner 도 이 형태다
Scanner sc = new Scanner(System.in);
```
