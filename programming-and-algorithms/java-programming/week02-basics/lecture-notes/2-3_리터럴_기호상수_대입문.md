## 1. 리터럴 (Literal)

- **리터럴**은 프로그램 안에 직접 적은 값이며, 변수를 초기화하는 데 쓴다.
- 타입에 따라 표기 방법이 다르다.

### 정수 리터럴

정수형은 10진수, 8진수, 16진수로 표기할 수 있다.

```java
int m = 15;     // 10진수
int m = 015;    // 8진수  (0으로 시작) → 10진수로 13
int m = 0x15;   // 16진수 (0x로 시작) → 10진수로 21
```

> 참고:
> - `0b1010`은 2진수 표기다(Java 7 이상).
> - `2_000_000`처럼 밑줄로 자릿수를 구분할 수 있다(Java 7 이상).
> - int 범위를 넘는 long 리터럴에는 `L`을 붙인다.

### 실수 리터럴

- `13.0`은 `13.`으로, `0.1234`는 `.1234`나 `1234E-4`로 쓸 수 있다.
- 실수값 뒤에 붙는 기호로 float형과 double형을 구분한다.

```java
float f = 12.3;    // 컴파일 오류 (12.3 은 double)
float f = 12.3f;   // 정상
double d = 12.3;   // 정상
```

> 📝 **필기: float vs double**
> - 자바는 소수점이 있는 숫자를 기본적으로 **double**로 인식한다. 예: `12.3`
> - 그래서 float 변수에 대입할 때는 숫자 뒤에 반드시 `f`를 붙인다. `12.3`은 double이고 `12.3f`가 float이다.
>
> 📝 **필기 (퀴즈 3번): 지수 표기**
> - `e2`는 **밑이 10인 지수**다. 즉 `e2` = ×10², `e-3` = ×10⁻³이다.
>   예: `8.35e5` = 835000.0, `4.987e-3` = 0.004987
>
> 📝 **필기 (퀴즈 4번): `78410000000`이나 `3.21`로 저장하면 안 되는가?**
> - **`float grade = 3.21;`은 컴파일 에러다.**
>   - 소수점 리터럴은 기본이 double(8바이트)이다.
>   - 그래서 float(4바이트)에 넣으면 데이터가 손실될 위험이 있다.
>   - `3.21f`처럼 `f`나 `F`를 붙여 float임을 알려야 한다.
> - **`double distance = 78400000000.0;`처럼 풀어 쓰는 것은 문법적으로 가능하다.**
>   - 하지만 내가 `78410000000`으로 잘못 적었던 것처럼, 0이 많아지면 오타가 나기 쉽다.
>   - 자릿수가 큰 숫자는 지수 표기 `7.84e10`을 그대로 쓰는 것이 좋다.

### 문자 리터럴

- 문자는 작은따옴표 `' '`로 감싼다.
- 큰따옴표 `" "`를 쓰면 **문자열**이 되니 주의한다.
- 문자의 코드 값으로도 표현할 수 있다.
- 자바는 **2바이트 유니코드**를 쓰므로 한 문자에 2바이트 코드가 부여된다.
- 유니코드는 `\u` 다음에 16진수 네 자리로 쓴다.

```java
char c = '\u0042';   // char c = 'B' 와 동일. 0042 는 'B' 의 유니코드 값
char c = '\uae00';   // char c = '글' 과 동일. ae00 은 '글' 의 유니코드 값
```

> ⚠ 슬라이드에는 `\ u0042`처럼 공백이 들어가 있고 따옴표도 빠져 있는데, `'\u0042'`로 써야 한다.

### 이스케이프 시퀀스 (Escape Sequence)

- 자바는 `\u`처럼 백슬래시로 시작하는 특수문자를 여러 개 제공하며, 이를 **이스케이프 시퀀스**라 한다.
- 백슬래시(`\`)나 큰따옴표(`"`) 자체를 쓰려면 앞에 백슬래시를 붙인다.

| 이스케이프 | 의미 |
|---|---|
| `'\b'` | 백스페이스 |
| `'\t'` | 탭 |
| `'\n'` | 줄 바꿈 (new line) |
| `'\r'` | 캐리지 리턴 (커서를 줄 맨 앞으로) |
| `'\\'` | 백슬래시 |
| `'\"'` | 큰따옴표 |
| `'\''` | 작은따옴표 |

> 📝 **필기 (퀴즈 6번):** `\b`는 공백을 **넣는** 것이 아니라 커서를 한 칸 뒤로 옮겨 앞 글자를 **지우는(덮어쓰는)** 효과를 낸다. 실제로 어떻게 보이는지는 콘솔마다 다를 수 있다.
> 경로를 쓸 때는 `"C:\\Users"`처럼 백슬래시를 두 번 쓴다.
> 📝 **필기:** 한글 윈도우 폰트에서는 `\`가 `₩`로 보이지만 같은 문자다.

### 논리 · null · 문자열 리터럴

- 논리형 값은 `true`(참)와 `false`(거짓) 두 가지뿐이다.
- 참조형 변수에는 `null`(아무 객체도 가리키지 않음)을 저장할 수 있다.
- String에는 문자열 리터럴을 쓸 수 있고, 큰따옴표로 감싼다.

```java
boolean b = true;          // boolean 타입
String str = null;         // null 저장 가능
String str = "I love you"; // String 타입
```

## 2. 기호 상수 (Symbolic Constant)

- 상수 값에 이름(기호)을 붙여, 값 대신 그 이름을 쓸 수 있다.
- 변수 선언과 비슷하지만 자료형 앞에 **`final`** 키워드를 붙인다는 점이 다르다.
- C++의 `const`와 비슷하다.
- 값을 바꿔야 할 때는 기호 상수의 정의만 고치면 된다.

```java
final double PI = 3.14159;
PI = 3.14;   // compile error: final 변수는 다시 대입할 수 없다
```

```java
final int SIZE = 10;            //  →  final int SIZE = 100;  한 줄만 바꾸면
// ...
int num1 = SIZE * price;        //     SIZE 를 사용한 모든 곳에 반영된다
```

> 📝 **필기 (실습 수식 2번)**
> - `final`은 상수를 선언한다. 한 번 값을 정하면 바꿀 수 없다.
> - ★ **기호 상수가 왜 좋은가?** 같은 값이 여러 군데에서 쓰일 때 그곳을 일일이 찾아 고칠 필요 없이, 상수를 선언한 한 곳만 고치면 된다.
> - 상수는 **앞줄에 선언**하는 것이 관례다. 변수와 기호 상수 선언은 위쪽에 모아 둔다.
> - 상수 이름은 보통 대문자로 쓴다. 예: `PYUNG`
> - `final float PYUNG = 3.3058f;`처럼 float 상수에도 `f`가 필요하다.
> → [`practice/expressions/PyungToSquareMeter.java`](../practice/expressions/PyungToSquareMeter.java), [`practice/expressions/TimeToSeconds.java`](../practice/expressions/TimeToSeconds.java)
>
> 📝 **필기 (퀴즈 5번): 틀린 코드 찾기**
> - `final double PI = 3.14;` 다음 줄의 `PI = 3.14159;`는 상수에 다시 대입하므로 컴파일 에러다.
> - `int x, y = 0;`은 y만 0으로 초기화한다. 둘 다 초기화하려면 `int x = 0, y = 0;`으로 쓴다.
> - `char grade = "A";`는 `'A'`로 고쳐야 한다.
> - `double rate = 10^10;`은 `^`가 XOR라서 결과가 0이다. `1e10`으로 쓴다.
> - `int salary = 2,000,000;`은 쉼표를 쓸 수 없다. `2_000_000`으로 쓴다.
> → [`quiz/VariableQuiz.java`](../quiz/VariableQuiz.java)

## 3. 대입문

- 메소드 안에는 필요한 변수를 선언하고, 그 변수를 쓰는 실행문을 쓴다.
- 가장 기본적인 실행문은 대입 연산자(`=`)를 쓰는 **치환문(대입문)** 이며, 변수에 값을 저장한다.

### 대입 연산자 `=`

- 대입 연산자는 오른쪽 수식의 값을 왼쪽 변수에 저장한다. **치환 연산자**라고도 한다.

```java
int x, y;
x = 10;       // 상수 값 저장
y = x;        // x 의 값을 y 에 저장
int z = 10;   // 선언과 동시에 초기화 가능
```

- 대입 연산자의 **왼쪽에는 변수만** 올 수 있다.
- 오른쪽에도 변수가 올 수 있으며, 이때는 그 변수에 저장된 값을 뜻한다.

```java
int a = 10, b = 5;
a + 1 = b;    // ✗ "a + 1" 은 변수가 아니므로 허용하지 않음
a = a + 1;    // a 에는 11 이 들어간다 (수학의 등호가 아님!)
a = b = 4;    // 오른쪽부터 실행된다 → b = 4, 그 결과(4)를 a 에 대입
```
