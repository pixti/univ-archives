## 1. 변수 선언

- **Python**에는 변수 선언이 없고, 변수에 아무 유형의 값이나 저장할 수 있다.
- **Java**는 변수를 반드시 선언해야 한다. 선언할 때 저장할 수 있는 유형(**type**)을 지정하며, 변수에는 지정된 유형의 값만 저장할 수 있다.
- 같은 변수는 **한 번만** 선언한다.
- 선언과 동시에 값을 초기화할 수 있다.

```java
// 한 줄에 여러 개 선언
int x, y, z;
double r1, r2;

// 위와 같은 의미
int x;
int y;
int z;
double r1;
double r2;
```

```java
// 선언 후 대입
int x;
int y;
int z;
x = 1;
y = 0;
z = -1;

// 선언과 동시에 초기화
int x = 1;
int y = 0;
int z = -1;
```

> 📝 **필기: 지역 변수의 초기화**
> - 메소드(예: `main`) 안에서 선언한 **지역 변수**는 자동으로 초기화되지 **않는다**.
> - 그래서 사용하기 전에 반드시 값을 넣어야 한다. 예를 들어 `int x; System.out.print(x);`는 컴파일 에러다.
> - 프로그래밍응용 시간에 배운 **인스턴스 변수**(필드)는 예외로, 자동으로 초기화된다(0, false, null).
> → [`practice/variables/Literal.java`](../practice/variables/Literal.java)

## 2. 기본 자료형 (Primitive Type)

| 자료형 | 값의 유형 | 크기 | 값의 범위 |
|---|---|---|---|
| `boolean` | true, false | 1 byte | `true`, `false` |
| `byte` | 정수 | 1 byte | -128 ~ 127 |
| `char` | 문자 | 2 byte | 유니코드 `\u0000` ~ `￿` (0 ~ 65535) |
| `short` | 정수 | 2 byte | -32768 ~ 32767 |
| `int` | 정수 | 4 byte | -2147483648 ~ 2147483647 |
| `long` | 정수 | 8 byte | -9223372036854775808 ~ 9223372036854775807 |
| `float` | 실수 | 4 byte | ±3.40282347E38 |
| `double` | 실수 | 8 byte | ±1.79769313486231570E308 |

> ⚠ 슬라이드의 float 범위 `3.40292347E38`은 오타이고, `3.40282347E38`(= `Float.MAX_VALUE`)이 맞다.
> 슬라이드에는 숫자 중간에 공백(`3. 40292347E38`)도 들어가 있는데, 실제 코드에서는 공백 없이 써야 한다.

> 📝 **필기 (퀴즈 1번):** 데이터마다 알맞은 자료형과 변수 이름을 정했다.
> - 학생 수와 시험 점수는 `int`이다.
> - 거리, 몸무게, 키, 빛의 속도는 `double`이다.
> - 변수 이름은 카멜 표기법(`studentCount`)을 쓴다. 스네이크 표기법은 `student_count`이다.
> - 제출본에서 "사람의 키" 선언문을 `double weight;`로 잘못 적었는데, `double height;`가 맞다.
> → [`quiz/VariableQuiz.java`](../quiz/VariableQuiz.java)
>
> 📝 **필기 (퀴즈 2번):** 틀린 변수 이름의 예
> - `#_of_workers`: `#`는 쓸 수 없다.
> - `comment-flag`: `-`는 빼기 연산자로 해석된다.
> - `1st_base`: 숫자로 시작한다.
> - `<x>`: `<`, `>`는 쓸 수 없다.
> - `class`: 예약어다.
>
> 올바른 이름은 `$person`, `_length`, `CountOfLettersInString`이다. 다만 마지막은 변수 첫 글자를 소문자로 쓰는 관례에 어긋난다.

### 변수 저장 예제

```java
public class VariablesTest {
    public static void main(String[] args) {
        boolean bln = true;              // true 또는 false 만 가능
        byte val1 = 127;
        char ch = 'a';                   // ch = '한'; 한글 저장 가능
        short val2 = 32767;
        int val3 = 214748364;
        long val4 = 9223372036854775807L;   // int 범위를 넘는 정수 리터럴은 L 필수
        float val5 = 3.40282347E38f;        // float 리터럴은 f 필수
        double val6 = 1.79769313486231570E308;
    }
}
```

> ⚠ 슬라이드 코드를 그대로 쓰면 컴파일되지 않는다. 고친 점은 다음과 같다.
> - `long`: int 범위를 넘는 리터럴에는 `L`을 붙여야 한다.
> - `float`: 소수점 리터럴은 기본이 double이라 `f`를 붙여야 한다.
> - 따옴표: `‘a’`처럼 전각 따옴표가 쓰여 있는데, 반각 `'a'`로 써야 한다.

## 3. 참조 자료형 (Reference Type)

- 참조 자료형은 **객체의 참조(주소)** 를 저장하는 자료형이다.
- 자바가 제공하는 클래스와 인터페이스, 또는 필요해서 직접 작성한 클래스와 인터페이스가 여기에 속한다.
- 기본 자료형과 달리, 선언만 해서는 객체가 자동으로 생성되지 않는다. **객체의 참조를 저장할 공간만** 확보된다.
- 그래서 참조형 변수는 선언할 때 객체를 만들어 초기화하거나, 선언한 뒤 나중에 객체를 만들어 그 참조를 저장한다.

```java
String s = new String("bmkim");   // 선언 시에 객체를 생성하여 초기화

String s;
s = new String("bmkim");          // 선언 후에 객체를 생성하여 초기화

String s = "bmkim";               // 편의상 기본 자료형처럼 사용 가능 (문자열 리터럴)
```

## 4. 변수명 (식별자) 규칙

1. 첫 글자는 문자나 특수문자 `_`, `$`로 시작해야 한다.
2. 숫자로 시작할 수 없다.
3. 첫 글자가 아니라면 문자, `_`, `$`, 숫자로 구성할 수 있다.
4. 자바의 예약어는 식별자로 쓸 수 없다.
5. 대소문자를 구분한다. `count`와 `Count`는 다른 변수다.
6. 길이 제한은 없지만 공백은 포함할 수 없다.

> 메소드, 클래스, 상수도 식별자 규칙을 따라야 한다.

```java
int _count, $price, age2;       // OK
int 2age;                       // ✗ 숫자로 시작
int my age;                     // ✗ 공백 포함
int class;                      // ✗ 예약어
```

### 자바 예약어 (키워드)

| | | | | |
|---|---|---|---|---|
| abstract | assert | boolean | break | byte |
| case | catch | char | class | const |
| continue | default | do | double | else |
| extends | false | final | finally | float |
| for | goto | if | implements | import |
| instanceof | int | interface | long | native |
| new | null | package | private | protected |
| public | return | short | static | super |
| switch | synchronized | this | throw | throws |
| transient | true | try | void | volatile |
| while | | | | |

> `const`와 `goto`는 예약만 되어 있고 실제로는 쓰이지 않는다. `true`, `false`, `null`은 정확히는 리터럴이지만 식별자로 쓸 수 없다는 점은 같다.
