## 1. 논리 연산자

`조건식1 논리연산자 조건식2` 또는 `논리연산자 조건식` 형태로 쓴다.

| e1 | e2 | e1 && e2 | e1 \|\| e2 | e1 ^ e2 | !e1 |
|:-:|:-:|:-:|:-:|:-:|:-:|
| true | true | true | true | false | false |
| true | false | false | true | true | false |
| false | true | false | true | true | true |
| false | false | false | false | false | true |

- `&&` (AND): 둘 다 true일 때만 true
- `||` (OR): 하나라도 true이면 true
- `^` (XOR): 둘이 다르면 true
- `!` (NOT): 반대로

> 참고: **단축 평가(Short-circuit)**
> - `&&`는 왼쪽이 false면, `||`는 왼쪽이 true면 오른쪽을 **아예 계산하지 않는다**.
> - 그래서 `(x != 0 && 10 / x > 1)`처럼 오른쪽 계산이 위험한 경우를 막을 수 있다.
> - `&`, `|`를 boolean에 쓰면 단축 평가 없이 양쪽을 모두 계산한다.
>
> 📝 **필기 (퀴즈 · 수식 2·5번):**
> - `(x >= 10) || (x < 30)`은 x에 어떤 값이 들어가도 **항상 참**이다.
> - `!(x == 20) && !(x == 30)`은 `(x != 20) && (x != 30)`과 같다.
> - `!(x > 20)`은 `x <= 20`과 같다.
> - 윤년 조건은 `(year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)`이다.
> - `&&`가 `||`보다 우선순위가 높다. 그래서 `ave >= 3.0 && (toefl >= 300 || toefl <= 700)`에서 괄호를 빼면 의미가 달라지므로 괄호가 꼭 필요하다.
> → [`quiz/ExpressionQuiz.java`](../quiz/ExpressionQuiz.java)

### [실습] 논리 연산자

```java
public class LogicOperation {
    public static void main(String[] args) {
        int x = 3, y = 9;
        System.out.println("논리 AND 테스트");
        System.out.println((x < y) + ", " + (x > 0) + " : " + (x < y && x > 0));
        System.out.println((x > y) + ", " + (x > 0) + " : " + (x > y && x > 0));
        System.out.println((x < y) + ", " + (x < 0) + " : " + (x < y && x < 0));
        System.out.println((x > y) + ", " + (x < 0) + " : " + (x > y && x < 0));
        System.out.println("논리 OR 테스트");
        System.out.println((x < y) + ", " + (x > 0) + " : " + (x < y || x > 0));
        System.out.println((x > y) + ", " + (x > 0) + " : " + (x > y || x > 0));
        System.out.println((x < y) + ", " + (x < 0) + " : " + (x < y || x < 0));
        System.out.println((x > y) + ", " + (x < 0) + " : " + (x > y || x < 0));
        System.out.println("논리 XOR 테스트");
        System.out.println((x < y) + ", " + (x > 0) + " : " + (x < y ^ x > 0));
        System.out.println((x > y) + ", " + (x > 0) + " : " + (x > y ^ x > 0));
        System.out.println((x < y) + ", " + (x < 0) + " : " + (x < y ^ x < 0));
        System.out.println((x > y) + ", " + (x < 0) + " : " + (x > y ^ x < 0));
        System.out.println("논리 NOT 테스트");
        System.out.println((x < y) + " : " + !(x < y));
        System.out.println((x > y) + " : " + !(x > y));
    }
}
```

> 문자열과 이어 붙일 때 `(x < y)`처럼 괄호를 꼭 친다. 괄호가 없으면 `+`가 `<`보다 먼저 계산되어 `"문자열" + x`가 된 뒤 `<` 비교를 하게 되고, 컴파일 에러가 난다.

## 2. 축약(복합) 대입 연산자

코드를 짧게 쓸 때 자주 사용한다.

| 축약 대입 | 의미 | 축약 대입 | 의미 |
|---|---|---|---|
| `a += b;` | `a = a + b;` | `a &= b;` | `a = a & b;` |
| `a -= b;` | `a = a - b;` | `a \|= b;` | `a = a \| b;` |
| `a *= b;` | `a = a * b;` | `a ^= b;` | `a = a ^ b;` |
| `a /= b;` | `a = a / b;` | `a >>= b;` | `a = a >> b;` |
| `a %= b;` | `a = a % b;` | `a >>>= b;` | `a = a >>> b;` |
| `a <<= b;` | `a = a << b;` | | |

> 참고:
> - 축약 대입은 **자동으로 강제 형변환**을 해 준다. `byte b = 10; b += 5;`는 OK다. 하지만 `b = b + 5;`는 int 결과라 컴파일 에러다.
> - `x *= y + 1`은 `x = x * (y + 1)`이다. 오른쪽 전체가 먼저 계산된다.

## 3. 증감 연산자

정수형 변수의 값을 1 증가시키거나 감소시키는 연산자다.

| 연산자 | 동작 |
|---|---|
| `++a` | a를 **증가시킨 후** a를 사용 (전위) |
| `a++` | a를 **사용한 후** a를 증가 (후위) |
| `--a` | a를 **감소시킨 후** a를 사용 (전위) |
| `a--` | a를 **사용한 후** a를 감소 (후위) |

```java
int a = 3;
int b = 0;
int c;
c = ++a + b;   // a = a + 1;  c = a + b;   → a=4, c=4
c = a++ + b;   // c = a + b;  a = a + 1;   → c=4, a=5
++a;           // 단독으로 쓰면 결과는 a++ 와 같다
// 감소 연산자도 같은 방식
```

### [실습] 증감 연산자

```java
public class IncDecOperation {
    public static void main(String[] args) {
        int a, b, c, d;
        a = 3; b = 5; c = 6;
        d = a++ + b++ - c--;      // 3 + 5 - 6 = 2
        System.out.println("a=" + a + " b=" + b + " c=" + c + " d=" + d);
        a = 3; b = 5; c = 6;
        d = ++a + ++b - --c;      // 4 + 6 - 5 = 5
        System.out.println("a=" + a + " b=" + b + " c=" + c + " d=" + d);
        a = 3; b = 5; c = 6;
        d = ++a + b++ - --c;      // 4 + 5 - 5 = 4
        System.out.println("a=" + a + " b=" + b + " c=" + c + " d=" + d);
    }
}
```

```
a=4 b=6 c=5 d=2
a=4 b=6 c=5 d=5
a=4 b=6 c=5 d=4
```

- a, b, c의 최종값은 세 경우 모두 같다. 차이는 수식 안에서 **증감 전 값을 쓰느냐, 증감 후 값을 쓰느냐**뿐이다.
- 슬라이드 코드의 출력문에는 공백이 없어서 `a=4b=6c=5d=2`처럼 붙어서 나온다. 보기 좋게 공백을 넣었다.

> 📝 **필기 (퀴즈 · 수식 1번):** `x = 5, y = 3, z = 2`일 때 결과는 다음과 같다.
> - `z = ++x + ++y;` → x=6, y=4, z=10
> - `z = x++ + ++y;` → x=6, y=4, z=9. 후위 `x++`는 기존 값 5를 수식에 쓴 뒤에 증가한다.
> - 피연산자는 항상 **왼쪽(x)부터** 평가된다. 자세한 내용은 [2-5 노트](2-5_수식_산술연산자.md)를 보라.

## 4. 조건 연산자 `?:`

- 연산자 중 유일한 **삼항** 연산자다.
- `조건 ? 피연산자1 : 피연산자2` 형태로 쓴다.
- 조건이 true이면 피연산자1, false이면 피연산자2가 결과가 된다.
- 간단한 if-else를 한 줄로 줄일 수 있다.

```java
a   = c > 0 ? 1 : 0;   // c 가 0 보다 크면 1, 아니면 0 을 a 에 대입
max = a > b ? a : b;   // a, b 중 최대값
abs = a > 0 ? a : -a;  // a 의 절대값
```

> - 조건 연산자는 **오른쪽 → 왼쪽**으로 결합한다. `a ? b : c ? d : e`는 `a ? b : (c ? d : e)`로 해석한다.
> - 중첩해서 쓸 수 있지만 가독성을 위해 괄호를 치는 편이 좋다.
>
> ⚠ 퀴즈 참고 자료의 결합 순위 표에는 `?:`가 `→`(왼쪽→오른쪽)로 적혀 있었다. 하지만 강의 슬라이드(2-5)와 자바 명세에 따르면 **오른쪽 → 왼쪽**이 맞다. → [`quiz/ExpressionQuiz.java`](../quiz/ExpressionQuiz.java)
>
> 💡 **과제 수식 4번 (사분면) 풀이:** 조건 연산자를 중첩해서 사분면을 판별한다.
> ```java
> int quadrant = (x > 0) ? ((y > 0) ? 1 : 4) : ((y > 0) ? 2 : 3);
> ```
> → [`assignment/expressions/Quadrant.java`](../assignment/expressions/Quadrant.java)

### [실습] 조건 연산자

```java
import java.util.Scanner;

public class ConditionOperation {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("첫 번째 숫자 (음수도 가능) >> ");
        int s1 = sc.nextInt();
        System.out.println("두 번째 숫자 (음수도 가능) >> ");
        int s2 = sc.nextInt();
        sc.close();
        s1 = s1 > 0 ? s1 : -s1;          // s1 의 절대값
        s2 = s2 > 0 ? s2 : -s2;          // s2 의 절대값
        int sum = s1 + s2;
        int max = s1 > s2 ? s1 : s2;
        System.out.println("절대값 합 : " + sum);
        System.out.println("절대값 최대 : " + max);
    }
}
```

```
첫 번째 숫자 (음수도 가능) >>
-3
두 번째 숫자 (음수도 가능) >>
5
절대값 합 : 8
절대값 최대 : 5
```
