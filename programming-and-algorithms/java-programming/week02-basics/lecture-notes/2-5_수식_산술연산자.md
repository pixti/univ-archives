## 1. 수식 (Expression)

- 대입 연산자의 오른쪽에는 변수와 상수 말고도 **수식**이 올 수 있다.
- 수식은 **피연산자**와 **연산자**가 결합한 것이다.
- 피연산자는 연산(계산)의 대상이다. 값, 변수, 또는 수식이 피연산자가 될 수 있다.

| 종류 | 형태 | 예 |
|---|---|---|
| 단항 연산자 | `연산자 피연산자` 또는 `피연산자 연산자` | `-x`, `!b`, `x++` |
| 이항 연산자 | `피연산자1 연산자 피연산자2` | `a + b` |
| 삼항 연산자 | `피연산자1 ? 피연산자2 : 피연산자3` | `a > b ? a : b` |

## 2. 연산자 우선순위 (위쪽일수록 먼저 계산)

| 순위 | 연산자 | 종류 |
|:-:|---|---|
| 1 | `expr++` `expr--` | 후위(postfix) 단항 |
| 2 | `++expr` `--expr` `+expr` `-expr` `~` `!` | 전위(prefix) 단항 |
| 3 | `*` `/` `%` | 곱셈 · 나눗셈 · 나머지 |
| 4 | `+` `-` | 덧셈 · 뺄셈 |
| 5 | `<<` `>>` `>>>` | 시프트 |
| 6 | `<` `>` `<=` `>=` `instanceof` | 관계 |
| 7 | `==` `!=` | 동일 |
| 8 | `&` | 비트 AND |
| 9 | `^` | 비트 XOR |
| 10 | `\|` | 비트 OR |
| 11 | `&&` | 논리 AND |
| 12 | `\|\|` | 논리 OR |
| 13 | `? :` | 삼항(조건) |
| 14 | `=` `+=` `-=` `*=` `/=` `%=` `&=` `^=` `\|=` `<<=` `>>=` `>>>=` | 대입 |

> - Python의 **지수 연산자 `**`** 와 **정수 나눗셈 연산자 `//`** 는 자바에 없다.
>   - 거듭제곱은 `Math.pow(a, b)`나 `x * x * x`로 계산한다.
>   - 정수끼리의 `/`는 원래 정수 나눗셈이다.
> - 슬라이드에서 빨간색으로 표시된 `++` `--` `>>>` `instanceof` `?:` 등은 Python에 없고 Java에만 있는 연산자다.
>
> 📝 **필기 (실습 수식 5번: 2차 방정식)**
> - 근의 공식 `(-b ± √(b² - 4ac)) / 2a`를 그대로 수식으로 옮긴다. 제곱근은 `Math.sqrt()`로 구한다.
> - `import java.lang.Math;`는 쓰지 않아도 된다. `java.lang`은 기본으로 import되는 패키지다.
> - 주의: `^`는 거듭제곱이 아니라 **비트 XOR**이다. `b^2`가 아니라 `b*b`로 써야 한다.
> - 주의: `(-b + tmp) / 2*a`로 쓰면 "2로 나눈 다음 a를 곱하는" 계산이 된다. 반드시 `(2*a)`처럼 괄호를 친다.
> → [`practice/expressions/QuadraticEquation.java`](../practice/expressions/QuadraticEquation.java), [`assignment/expressions/Polynomial.java`](../assignment/expressions/Polynomial.java)
>
> 📝 **필기 (실습 수식 4번: 복리 계산)**
> - 원금 x는 1년 뒤 `x + x*r`가 된다.
> - 2년 뒤에는 그 금액을 다시 원금으로 삼아 `(x + x*r) + (x + x*r)*r` = `x * (1 + r) * (1 + r)`가 된다.
> → [`practice/expressions/Savings.java`](../practice/expressions/Savings.java)

## 3. 결합 법칙 (Associativity)

- 연산은 우선순위에 따라 진행한다.
- 우선순위가 같으면 **결합 법칙**에 따라 처리한다.
  - **대입 연산자를 뺀 모든 이항 연산자**는 왼쪽 → 오른쪽으로 연산한다.
  - **단항(unary) 연산자, 삼항 연산자, 대입 연산자**는 오른쪽 → 왼쪽으로 연산한다.

```java
x = y - 3 + z;       // ① y - 3   ② (①) + z   ③ x = (②)
x = y - (3 + z);     // ① 3 + z   ② y - (①)   ③ x = (②)
```

> 📝 **필기 (퀴즈 · 수식 1번): 전위 증가는 y 다음 x 순서가 아니라 x 다음 y 순서인가?**
> - x가 먼저 처리되고 그다음 y가 처리된다.
> - 자바는 연산자 우선순위와 별개로 **피연산자(항)를 무조건 왼쪽에서 오른쪽으로 평가**한다는 규칙이 있다.
> - `x = 5, y = 3`일 때 `z = ++x + ++y;`의 실행 순서는 다음과 같다.
>   1. 왼쪽 항 `++x`를 먼저 계산한다 → 6
>   2. 오른쪽 항 `++y`를 계산한다 → 4
>   3. 덧셈 `6 + 4` = 10
>   4. 우선순위가 가장 낮은 `=`가 마지막에 실행되어 z에 10이 저장된다.
> - C/C++은 컴파일러에 따라 오른쪽 항을 먼저 계산하기도 한다. 자바는 어디서 실행해도 결과가 같도록 왼쪽부터 처리하는 것을 언어 스펙으로 강제한다.
>
> 📝 **필기 (퀴즈 · 수식 1·3번): 대입 연산자의 결합 방향**
> - `x += y -= 2;`는 오른쪽의 `y -= 2`가 먼저 실행된다.
> - `x = y = z % w`는 `%` → 오른쪽 `=` → 왼쪽 `=` 순서로 실행된다.
> - `x % y / z * w`는 우선순위가 같으므로 왼쪽부터 `%` → `/` → `*` 순서다.
> → [`quiz/ExpressionQuiz.java`](../quiz/ExpressionQuiz.java) (우선순위 · 결합 순위 참고표 포함)

## 4. 산술 연산자

| 연산자 | 의미 | 예 (`int`) |
|---|---|---|
| `+` | 덧셈 | `7 + 2` → 9 |
| `-` | 뺄셈 | `7 - 2` → 5 |
| `*` | 곱셈 | `7 * 2` → 14 |
| `/` | 나눗셈 (정수끼리는 **몫**) | `7 / 2` → 3 |
| `%` | 나머지 | `7 % 2` → 1 |

### 산술 연산 시 주의할 것

**① 실수형 수식을 정수형 변수에 저장하는 경우**
```java
float x = 2.0f, y = 3.0f;
int z = (int) (y / x);   // 1.5 가 아닌 1 이 저장된다
```

**② 정수끼리 나눈 결과를 실수형 변수에 저장하는 경우**
```java
int x = 2, y = 3;
double z = y / x;        // 1.5 가 아닌 1.0 이 저장된다 (정수 나눗셈 3/2=1 이 먼저 일어남)
```

**③ 원하는 값을 정확히 저장하려면** 나누기 **전에** 피연산자 하나를 실수로 바꾼다.
```java
double z = (double) y / x;   // 1.5   ← 형변환이 / 보다 우선순위가 높다
double z = y / (double) x;   // 1.5

// 주의! 이미 계산된 정수값 1 을 1.0 으로 바꿔주는 것에 불과!
double z = (double) (y / x); // 1.0
```

> ⚠ 슬라이드의 `float x = 2.0, y = 3.0;`은 double 리터럴이라 컴파일 에러다. `2.0f`, `3.0f`로 써야 한다.
>
> 💡 **과제 수식 2번 (평균 점수) 풀이 중:** `sum / 4`는 정수 나눗셈이라 소수점이 버려진다. `sum / 4.0`이나 `(double) sum / 4`로 써야 한다. → [`assignment/expressions/AverageScore.java`](../assignment/expressions/AverageScore.java)

## 5. [실습] 양의 정수를 시·분·초로 변환하기

입력이 `3665`이면 `1시 1분 5초`, `65`이면 `0시 1분 5초`를 출력한다.

```java
import java.util.Scanner;

public class IntegerToTime {
    public static void main(String[] args) {
        System.out.println("숫자 입력 >> ");
        Scanner sc = new Scanner(System.in);   // Scanner 객체 생성
        int i = sc.nextInt();                  // 정수 입력
        sc.close();                            // 사용 후 꼭! 닫아줌
        int hour = i / 3600;                   // 1시간 = 3600초
        int remain = i % 3600;                 // 시간을 빼고 남은 초
        int minute = remain / 60;
        int second = remain % 60;
        System.out.println(hour + "시 " + minute + "분 " + second + "초");
    }
}
```

> `/`로 몫을 구하고 `%`로 나머지를 넘기는 패턴은 과제 [`DigitSplit.java`](../assignment/expressions/DigitSplit.java)(자릿수 분리)와 실습 [`TimeToSeconds.java`](../practice/expressions/TimeToSeconds.java)에서도 쓴다.

## 6. [실습] 학생 3명의 성적을 입력받아 총점과 평균 구하기

```java
import java.util.Scanner;

public class SumNAvg {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("첫 번째 성적 >> ");
        int s1 = sc.nextInt();
        System.out.println("두 번째 성적 >> ");
        int s2 = sc.nextInt();
        System.out.println("세 번째 성적 >> ");
        int s3 = sc.nextInt();
        sc.close();
        int sum = s1 + s2 + s3;
        double avg = sum / 3.0;        // 3 이 아니라 3.0 으로 나눠야 실수 나눗셈
        System.out.println("합 : " + sum);
        System.out.println("평균 : " + avg);
    }
}
```

## 7. 오버플로우와 언더플로우

- 자료형마다 저장할 수 있는 값의 범위가 정해져 있다.
- 값이 범위보다 크거나(**오버플로우**) 작으면(**언더플로우**) 엉뚱한 결과가 나온다. 값이 반대쪽 끝으로 돌아간다.
- 각 기본형의 대응 클래스(Wrapper Class)는 최대값 `MAX_VALUE`와 최소값 `MIN_VALUE`를 정적(static) 필드로 제공한다.

| 자료형 | 대응 클래스 | 자료형 | 대응 클래스 |
|---|---|---|---|
| `boolean` | `Boolean` | `byte` | `Byte` |
| `char` | `Character` | `short` | `Short` |
| `int` | `Integer` | `long` | `Long` |
| `float` | `Float` | `double` | `Double` |

```java
public class Overflow {
    public static void main(String[] args) {
        int x = Integer.MAX_VALUE;   // int 형의 최대값
        int y = Integer.MIN_VALUE;   // int 형의 최소값
        System.out.println("x = " + x);
        System.out.println("y = " + y);
        int w = x + 1;               // 오버플로우
        int z = y - 1;               // 언더플로우
        System.out.println("w = " + w);
        System.out.println("z = " + z);
    }
}
```

```
=== 결과 ===
x = 2147483647
y = -2147483648
w = -2147483648
z = 2147483647
```
