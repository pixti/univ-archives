## 1. 다음 데이터를 표현하는 데 가장 바람직한 자료형과 변수 이름을 결정하고 변수 선언 문장을 써 보아라.

```text
| 데이터                   | 자료형 | 변수 이름     | 변수 선언 문장          |
```

|--------------------------|--------|---------------|-------------------------|

```text
| 한 학급의 학생 수         | int    | studentCount  | int studentCount;       |
| 두 물체 사이의 거리(실수형) | double | distance      | double distance;        |
| 사람의 몸무게             | double | weight        | double weight;          |
| 사람의 키                 | double | height        | double height;          |
| 시험 점수                 | int    | score         | int score;              |
| 빛의 속도(실수형)          | double | speedOfLight  | double speedOfLight;    |
```

**📝 필기**

- 스네이크 표기법(snake\_case): 단어 사이를 \_ 로 연결   예) student\_count
- 카멜 표기법(camelCase)    : 두 번째 단어부터 첫 글자를 대문자로   예) studentCount<br>→ 자바 변수명은 카멜 표기법이 관례
- 몸무게와 키는 int 나 double 이 상식적 (소수점까지 필요하면 double)

#### 💻 확인 코드

```java
// 1. 다음 데이터를 표현하는 데 가장 바람직한 자료형과 변수 이름을 결정하고 변수 선언 문장을 써 보아라.
```

## 2. 다음 변수 이름이 올바른지 아니면 잘못되었는지를 지적하고 그 이유를 써라.

```text
| 변수 이름              | 유효 | 이유                                                   |
```

|------------------------|------|--------------------------------------------------------|

```text
| #_of_workers           | X    | 특수문자 # 는 허용되지 않음                              |
| CountOfLettersInString | O    | 정상 작동. 단, 변수는 첫 글자가 소문자인 것이 관례          |
| comment-flag           | X    | 특수문자 - 는 허용되지 않음 (빼기 연산자로 해석됨)          |
| $person                | O    | 특수문자 $ 는 허용됨                                     |
| 1st_base               | X    | 숫자로 시작하는 것은 허용되지 않음                         |
| <x>                    | X    | < , > 는 허용되지 않음                                   |
| class                  | X    | 예약어 class 는 식별자로 사용 불가                        |
| _length                | O    | 특수문자 _ 는 허용됨                                     |
```

**식별자 규칙 (2-2 강의)**

- 첫 글자는 문자나 '\_', '$' 로 시작 (숫자로 시작 불가)
- 첫 글자가 아니면 문자, '\_', '$', 숫자로 구성 가능
- 예약어(키워드) 사용 불가, 대소문자 구분, 길이 제한 없음, 공백 포함 불가
- 참고) Java 9 부터는 밑줄 하나만 있는 \_ 단독은 키워드라 사용 불가 (\_length 는 OK)

**📝 필기**

- 상수명이나 클래스명은 보통 대문자로 시작하고, 변수명은 소문자로 시작하는 것이 관례.

## 4. 다음 설명에 적합한 변수 선언문을 작성하라.

- ① 정수의 합을 저장하는 변수 sum                                   → int sum;
- ② 정밀도가 낮은 실수형 점수를 저장하는 변수 score                   → float score;
- ③ 정밀도가 높은 실수형 비율을 저장하는 변수 rate                    → double rate;
- ④ 문자를 저장하는 변수 answer                                     → char answer;
- ⑤ 정밀도가 낮은 실수를 저장하는 변수로 초기값이 3.21 인 변수 grade   → float grade = 3.21f;
- ⑥ 정밀도가 높은 실수를 저장하는 변수로 초기값이 7.84e10 인 변수 distance → double distance = 7.84e10;

- 📝 필기 (질문: 3.21 이나 78400000000.0 으로 저장하면 안 되나?)
- float grade = 3.21; 로 쓰면 안 되는 이유 (컴파일 에러)
  - 자바는 소수점이 있는 숫자(리터럴)를 기본적으로 정밀도가 높은 double 형(8바이트)으로 인식.
  - 더 큰 double 값을 정밀도가 낮은 float 변수(4바이트)에 그대로 넣으려 하면 데이터 손실 위험이 있다고 판단하여 컴파일 에러 발생.
  - 그래서 "이 숫자는 double 이 아니라 float 형이다" 라고 알려주기 위해<br>반드시 숫자 끝에 f 나 F 를 붙여야 한다. (3.21f)
- 78400000000\.0 으로 풀어 쓰는 경우 (7.84e10)
  - double distance = 78400000000.0; 처럼 일반 실수 형태로 저장하는 것은 문법적으로 가능.
  - 하지만 0 이 많아지면 입력 과정에서 자릿수를 잘못 세기 매우 쉽다.
  - ⚠ 자주 틀리는 부분: 7.84e10 을 78410000000 처럼 숫자를 이어 붙이면 안 된다.<br>소수점을 오른쪽으로 10칸 옮긴 78,400,000,000 이 맞다.
  - 문제에서 지수 표기법을 제시하기도 했고, 실무에서도 자릿수가 큰 숫자는 가독성과 휴먼 에러 방지를 위해 지수 표기법(e)을 그대로 쓰는 것이 권장된다.

#### 💻 확인 코드

<!-- code: VariableQuiz.java#q4 -->
```java

    double distance2 = 78400000000.0; // 문법적으로 가능하지만 오타 위험

            + ", 같은 값? " + (distance == distance2));
```

## 5. 다음의 코드에서 잘못된 부분을 모두 지적하라.

```java
public class Test {
    public void main(String[] args)
    {
        int x, y = 0;          // x와 y를 모두 0으로 초기화
        char grade = "A";
        double rate = 10^10;   // rate에 1*10^10을 저장
        int salary = 2,000,000;
        final double PI = 3.14;
        PI = 3.14159;
    }
}
```

**① public void main(String\[] args)**

→ 프로그램 시작점인 main 메소드는 반드시 static 을 포함해야 한다.<br>올바른 형태: public static void main(String\[] args)<br>(참고: JDK 25 부터는 static 없는 인스턴스 main 도 실행되지만(JEP 512), 수업 기준으로는 오류다.)

**② int x, y = 0;**

→ 주석("x와 y를 모두 0으로 초기화")의 의도와 다르게 y 만 0 으로 초기화되고 x 는 선언만 된다.

```java
둘 다 초기화하려면 int x = 0, y = 0;
```

**③ char grade = "A";**

→ char 리터럴은 작은따옴표 ' ' 로 감싸야 한다. 큰따옴표 " " 는 문자열(String).<br>자료형 불일치 에러 → 'A' 로 수정

**④ double rate = 10^10;**

→ 자바에서 ^ 는 거듭제곱이 아니라 비트 배타적 논리합(XOR) 연산자. (10 ^ 10 = 0)<br>1 × 10¹⁰ 을 저장하려면 지수 표기법 1e10 또는 Math.pow(10, 10) 사용

**⑤ int salary = 2,000,000;**

→ 숫자 리터럴에 쉼표(,)를 넣을 수 없어 문법 에러.<br>2000000 으로 붙여 쓰거나, Java 7 이상에서는 가독성을 위해 2\_000\_000 처럼 언더스코어 사용 가능

**⑥ PI = 3.14159;**

→ PI 는 final 이 붙은 상수. 한 번 초기화되면 값을 다시 할당할 수 없어 컴파일 에러.

#### 💻 확인 코드

<!-- code: VariableQuiz.java#q5 -->

## 6. 다음 이스케이프 시퀀스의 의미는 무엇인가?

```text
| 이스케이프 시퀀스 | 의미                     |
```

|-------------------|--------------------------|

```text
| \t                | Tab 만큼 커서 이동         |
| \b                | 커서 한 칸 앞 이동 (백스페이스) |
| \n                | 줄바꿈                    |
```

- 한글 윈도우에서는 백슬래시 \\ 가 원화 기호 ₩ 로 보인다. (같은 문자)

```text
| 순위 | 연산자                                         | 내용                  |
```

|------|------------------------------------------------|-----------------------|

```text
| 1    | () []                                          | 괄호 / 대괄호          |
| 2    | ! ~ ++ --                                      | 부정 / 증감 연산자      |
| 3    | * / %                                          | 곱셈 / 나눗셈 연산자    |
| 4    | + -                                            | 덧셈 / 뺄셈 연산자      |
| 5    | << >> >>>                                      | 비트 단위 시프트 연산자 |
| 6    | < <= > >=                                      | 관계 연산자            |
| 7    | == !=                                          |                       |
| 8    | &                                              | 비트 단위 논리 연산자   |
| 9    | ^                                              |                       |
| 10   | |                                              |                       |
| 11   | &&                                             | 논리곱 연산자          |
| 12   | ||                                             | 논리합 연산자          |
| 13   | ? :                                            | 조건 연산자            |
| 14   | = += -= *= /= %= <<= >>= >>>= &= ^= |=         | 대입 / 할당 연산자      |
```

**결합 순위 (우선순위가 같을 때의 연산 방향)**

- 단항 연산자 (++ -- + - \~ ! (타입))     : 오른쪽 → 왼쪽  ←
- 산술 / 시프트 / 비교 / 논리 (이항) : 왼쪽 → 오른쪽  →
- 삼항(조건) 연산자 ? :               : 오른쪽 → 왼쪽  ←
- 대입 연산자 (= \*= /= %= += -= ...)  : 오른쪽 → 왼쪽  ←

- ⚠ 주의: 삼항 연산자는 오른쪽 → 왼쪽으로 결합한다.<br>예) a ? b : c ? d : e  ==  a ? b : (c ? d : e)

## 1. int x = 5, y = 3, z = 2; 일 때 각 변수에는 어떤 값이 저장되는가? (각 문항은 독립적으로 계산)

**① x += y -= 2;**

    - 대입 연산자는 오른쪽에서 왼쪽으로 처리된다.
    - 먼저 y -= 2 가 실행되어 y 는 1 (3 - 2 = 1)
    - 그 후 x += 1 이 되어 x 는 6 (5 + 1 = 6)

→ 결과: x = 6, y = 1, z = 2

**② x \*= y + 2;**

    - 산술 연산자(+)가 복합 대입 연산자(\*=)보다 우선순위가 높다.
    - 먼저 y + 2 가 계산되어 5 (3 + 2 = 5)
    - 그 후 x \*= 5 가 되어 x 는 25 (5 \* 5 = 25)

→ 결과: x = 25, y = 3, z = 2

**③ z = ++x + ++y;**

    - 전위 증가 연산자(++변수)는 값을 먼저 1 증가시킨 후 연산에 사용한다.
    - ++x 가 실행되어 x 는 6, ++y 가 실행되어 y 는 4
    - z = 6 + 4 가 계산되어 z 는 10

→ 결과: x = 6, y = 4, z = 10

**④ z = x++ + ++y;**

    - 후위 증가 연산자(변수++)는 현재 값을 먼저 연산에 사용한 후 나중에 1 증가시킨다.<br>따라서 수식에는 x 의 기존 값 5 가 사용되고, 그 직후에 x 는 6 으로 증가.
    - 전위 증가 연산자(++y)는 먼저 1 증가시키므로 y 는 4 가 되고 수식에도 4 가 사용.
    - z = 5 + 4 가 계산되어 z 는 9

→ 결과: x = 6, y = 4, z = 9

- 📝 필기 (질문: 전위증가연산자는 y 다음 x 순서가 아니라 x 다음 y 임?)
- x 가 먼저 처리되고 그다음 y 가 처리되는 것이 맞다.
- 자바는 수식을 계산할 때 "피연산자(항)를 무조건 왼쪽에서 오른쪽(Left-to-Right) 순서로 평가"한다는 엄격한 규칙이 있다. 연산자 우선순위와는 별개로, 수식 안의 변수나 값을 읽어오는 기본 방향 자체가 왼쪽부터.
- z = ++x + ++y; 의 정확한 내부 실행 순서<br>1단계 (왼쪽 항 평가)  : + 를 기준으로 왼쪽 항 ++x 를 먼저 실행 → x 가 5 → 6 (왼쪽은 6 으로 확정)<br>2단계 (오른쪽 항 평가): 다음으로 오른쪽 항 ++y 를 실행 → y 가 3 → 4 (오른쪽은 4 로 확정)
  ```text
  3단계 (덧셈 연산)     : 양쪽 값이 모두 준비되었으므로 6 + 4 = 10
  4단계 (대입 연산)     : 우선순위가 가장 낮은 대입 연산자(=)가 마지막에 실행되어 z 에 10 저장
  ```
- 참고: C/C++ 같은 일부 언어는 컴파일러 최적화 방식에 따라 오른쪽 항을 먼저 계산하기도 하지만, 자바는 어떤 컴퓨터에서 실행하든 결과가 똑같도록 '왼쪽부터 순서대로 처리'를 언어 스펙으로 강제한다.

#### 💻 확인 코드

```java
// 1. int x = 5, y = 3, z = 2; 일 때 각 변수에는 어떤 값이 저장되는가? (각 문항은 독립적으로 계산)

    x += y -= 2;
```

## 2. 다음 논리 연산을 설명해 보아라.

**① (x >= 10) || (x &lt; 30)**

    - 의미: x 가 10 이상이거나(OR), x 가 30 미만일 때 참.
    - 참고: 모든 숫자는 "10 이상" 또는 "30 미만" 중 하나는 무조건 만족하므로, x 에 어떤 값이 들어가도 항상 참(true)이 되는 식.

**② !(x == 20) && !(x == 30)**

    - 의미: x 가 20 이 아니고(AND), 동시에 x 가 30 도 아닐 때 참.
    - 참고: 부정 연산자(!)를 안으로 넣어 (x != 20) && (x != 30) 으로 써도 완전히 동일.

**③ (x == 30) || !(x > 20)**

    - 의미: x 가 30 이거나(OR), x 가 20 보다 크지 않을 때 참.
    - 참고: "20 보다 크지 않다" = "20 이하" 이므로 (x == 30) || (x &lt;= 20) 으로 바꿔 써도 같다.

#### 💻 확인 코드

<!-- code: ExpressionQuiz.java#q2 -->
```java
// 2. 다음 논리 연산을 설명해 보아라.
static void q2() {
    int[] samples = {5, 20, 25, 30, 40};

        boolean r1 = (x >= 10) || (x < 30);
        boolean r2 = !(x == 20) && !(x == 30);
        boolean r3 = (x == 30) || !(x > 20);
        System.out.println("[Q2] x=" + x + " → ① " + r1 + ", ② " + r2 + ", ③ " + r3);
    }
}
```

## 3. 다음 수식에서 연산자 밑에 계산 순서를 숫자로 적어 보아라.

**① x = y + z + 10**

```text
3   1   2
```


    - 계산 순서: 1. + (왼쪽) → 2. + (오른쪽) → 3. =
    - 덧셈(+)이 대입(=)보다 우선순위가 높다. 같은 + 끼리는 왼쪽에서 오른쪽으로 결합.

**② x % y / z \* w**

```text
1   2   3
```


    - 계산 순서: 1. % → 2. / → 3. \*
    - %, /, \* 는 모두 우선순위가 같으므로 기본 규칙대로 왼쪽에서 오른쪽 순서.

**③ x = y = z % w**

```text
3   2   1
```


    - 계산 순서: 1. % → 2. = (오른쪽) → 3. = (왼쪽)
    - 나머지(%)가 가장 먼저. 대입 연산자(=)가 여러 개일 때는<br>다른 연산자와 달리 오른쪽에서 왼쪽 방향으로 결합하여 값을 할당한다.

#### 💻 확인 코드

```java
// 3. 다음 수식에서 연산자 밑에 계산 순서를 숫자로 적어 보아라.

    x = y + z + 10;

    System.out.println("[Q3-②] " + r + " == ((17 % 7) / 3) * 4 = " + (((17 % 7) / 3) * 4));

    x = y = z % w;
    System.out.println("[Q3-③] x=" + x + ", y=" + y + " (z % w = " + (z % w) + ")");
}
```

## 4. 다음 문장에 해당하는 조건식을 써 보아라.

**① x 는 짝수이다.                → x % 2 == 0**

**② x 는 5 의 배수이다.            → x % 5 == 0**

**③ x 는 3 과 같거나 7 이하이다.    → x == 3 || x &lt;= 7**

(참고: 논리적으로는 x &lt;= 7 만 써도 3 인 경우를 포함하지만, 문장을 그대로 직역하면 위와 같다.)

**④ x 가 0 이상이고 100 이하이다.   → x >= 0 && x &lt;= 100**

(참고: 프로그래밍에서는 0 &lt;= x &lt;= 100 처럼 한 번에 쓸 수 없으므로 && 로 묶어야 한다.<br>자바에서 0 &lt;= x &lt;= 100 은 (0 &lt;= x) 가 boolean 이 되어 boolean &lt;= int 비교 → 컴파일 에러)

- ⑤ x 가 1 도 아니고 100 도 아니다. → x != 1 && x != 100

## 5. 다음 조건에 해당하는 논리 연산식을 만들어 보자.

- ① 무주택 기간(year) 3년 이상, 가구주의 연령(age)이 40세 이상, 가족의 수(count)가 3명 이상<br>→ year >= 3 && age >= 40 && count >= 3

**② 나이(age) 6세 이하, 키(height)는 150cm 이상**

→ age &lt;= 6 && height >= 150

- ③ 4의 배수이면서 100의 배수가 아닌 연도(year). 단 400의 배수는 포함<br>→ (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)<br>참고: 프로그래밍에서 윤년을 판별할 때 사용하는 대표적인 표준 논리식.
- ④ 평균 학점(ave) 3.0 이상이고, 토플 점수(toefl) 300점 이상이거나 700점 이하<br>→ ave >= 3.0 && (toefl >= 300 || toefl &lt;= 700)<br>참고: 문장("300점 이상이거나 700점 이하")을 그대로 직역한 결과.<br>다만 이 조건은 모든 점수를 포함하게 되므로, 출제 의도가 "300점 이상이면서 700점 이하" 였다면 괄호 안을 (toefl >= 300 && toefl &lt;= 700) 으로 쓰는 것이 자연스럽다.
    - ⚠ && 가 || 보다 우선순위가 높으므로 괄호를 빼면 (ave >= 3.0 && toefl >= 300) || toefl &lt;= 700 이 되어 의미가 달라진다. 괄호 필수!
